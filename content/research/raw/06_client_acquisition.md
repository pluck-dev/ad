### 1.2 전송 인프라(Deliverability) 세팅 [출처: MailReach, Instantly, UnifyGTM, howmanycoldemailsperday]

- **절대 본 도메인으로 보내지 말 것.** 보조 도메인(예: `brand-hq.com`, `getbrand.co`) 3~5개 구매.
- **도메인당 메일박스 1개**가 원칙 (MailReach). 한 도메인에 여러 계정 두면 하나 걸렸을 때 전부 오염.
- 메일박스당 하루 **50~100통** (MailReach는 80통 상한 권고). 150통 넘기면 스팸률 43% 상승.
- 워밍업: 신규 도메인은 등록 후 2주 대기 → 5~10통/일부터 4~6주 점진 증가 → 발송 중에도 전송량의 15% 수준 워밍 유지.
- SPF/DKIM/DMARC 필수, 바운스율 2% 미만 유지, 커스텀 트래킹 도메인 사용.
- **하루 1,000통 계산 예시** (MailReach): 1,000 ÷ 80 = 최소 13개 메일박스 = 13개 도메인.
- 비용 [추정]: 도메인 13개 × 연 $10 + Google Workspace 13석 × $7 ≈ 월 $100 + 발송툴 $47~94 → **월 $150~200이면 하루 1,000통 인프라 구축 가능**.

### 1.3 전환 수치 — "1,000통 보내면 무슨 일이 생기나"

**[출처: Instantly Cold Email Benchmark Report 2026]** (2025년 1~12월, 수십억 건 분석)
- 평균 답장률 **3.43%**, 상위 25% **5.5%+**, 상위 10% **10.7%+**
- 첫 메일이 전체 답장의 **58%**, 후속 2~7단계가 **42%**
- 최적 길이 **80단어 미만**, 시퀀스 **4~7 터치**, CTA는 하나(이진 질문)
- 월요일 런칭 → 수요일 답장 최다 → 금요일은 자동응답 폭증
- 2025년 최고 성과 CTA: *"Would you have a couple minutes to chat about this over the next few days?"*
- 상위 팀은 리서치·시퀀싱 작업의 **약 80%를 AI 에이전트**가 처리

**[출처: The Digital Bloom 2025 benchmarks]** — 훅 유형별
| 훅 유형 | 답장률 | 미팅률 | 긍정 답장 비율 |
|---|---|---|---|
| Timeline(타임라인: "X가 Y를 Z주 만에") | 10.01% | 2.34% | 65% |
| Numbers(숫자) | 8.57% | 1.86% | 62% |
| Social Proof(사회적 증거) | 6.53% | 1.25% | 53% |
| Problem(문제 제기) | 4.39% | 0.69% | 48% |
- 깊은 개인화(리서치+맞춤 맥락) **+52% 답장 상승**, 단순 머지태그는 +20~25%
- 50명 이하 마이크로 세그먼트가 1,000명 대량 발송 대비 **2.76배** 답장률
- 후속 스케줄 "3-7-7" (D0 → D3 → D10 → D17): 10일차까지 전체 답장의 93% 회수. 두 번째 후속 이후는 효과 미미
- CEO/창업자 답장률 7.63% (C레벨이 비C레벨보다 23% 높음)

**퍼널 계산 [추정, 보수적]**
```
1,000통 발송 (평균 3.4% 답장)
 → 34 답장
 → 긍정 답장 ~50% = 15~17
 → 미팅 성사 ~40~50% = 6~8 (노쇼 감안)
 → 미팅→계약 20~30% = 1~2 계약
```
상위 10% 수준(10% 답장, 긍정 65%)이면 같은 1,000통에서 **미팅 15~25, 계약 4~6**. 결국 **"타겟 세그먼트를 좁히고 타임라인 훅 + 무료 제작물"**이 격차를 만든다.

### 1.5 AI 개인화 실무 [출처: Instantly 리포트 + lemlist/Clay 기능 설명]
- 리드 목록(네이버 플레이스/인스타/구글맵 스크랩 또는 Apollo/Instantly DB) → 각 리드에 대해 LLM이 "관찰 한 줄"(최근 게시물, 리뷰 불만, 영상 부재 등) 생성 → 머지태그로 삽입.
- 개인화 변수는 **1~2개**만. 과한 개인화는 오히려 스팸처럼 보임 [통념].
- 사용자(당신)는 쇼츠/블로그 자동 생성 파이프라인이 있으므로, **"리드별 샘플 쇼츠 1개 자동 생성 → 썸네일 GIF 첨부 → 링크"** 형태의 초개인화가 가장 강한 차별점이 된다 [추정].

### 1.6 한국 법규: 정보통신망법 제50조 (사전동의) [출처: law.go.kr, KISA 불법스팸대응센터, sis.pe.kr 정리]

- **원칙**: "누구든지 전자적 전송매체를 이용하여 **영리목적의 광고성 정보**를 전송하려면 그 수신자의 **명시적인 사전 동의**를 받아야 한다." (옵트인)
- **영리목적 광고성 정보 정의**: 전송자가 경제적 이득을 취할 목적으로 보내는 ① 전송자에 관한 정보 ② 전송자가 제공할 재화/서비스에 관한 정보. **부수적 영리 목적도 포함**, 자연인·법인 모두 적용.
- **수신자가 사업자(B2B)여도 예외 없음.** 법 조문은 "수신자"를 개인/사업자로 구분하지 않는다. 사업자 대표 이메일이라도 광고성 정보를 보내려면 사전동의가 원칙.
- **사전동의 예외** (2가지):
  1. 거래관계를 통해 직접 연락처를 수집한 경우, 거래 종료일부터 **6개월 이내**, 같은 종류의 재화/서비스 광고
  2. 「방문판매법」상 전화권유판매자가 개인정보 수집 출처를 고지하고 전화로 권유하는 경우
- **야간 전송 제한**: 오후 9시 ~ 다음날 오전 8시는 별도 동의 필요 (문자/전화. 이메일은 야간 제한 적용 제외 [통념])
- **표기 의무 [통념, 시행령 기준]**: 제목 맨 앞 "(광고)", 전송자 명칭·연락처, 수신거부(무료) 방법 명시.
- **과태료 [통념]**: 위반 시 **3천만 원 이하 과태료**(제76조). 실무적으로 소량 1:1 제안 메일이 단속된 사례는 드물지만, 대량 자동발송(Instantly 등)을 국내 리스트에 돌리면 신고 리스크가 실제로 있다.
- **실무 판단 [추정]**:
  - 국내: 홈페이지·플레이스에 공개된 대표 메일로 **소량(하루 10~30통) 수작업 1:1 제안 메일** — "협업 제안" 성격이더라도 법적으로는 광고성 정보에 해당할 수 있음을 인지하고, 형식 요건(광고 표기·수신거부)을 갖추고, 수신거부 즉시 반영. 대량 자동화는 하지 않는다.
  - 해외(미국 CAN-SPAM은 옵트아웃 방식, EU는 GDPR 정당한 이익 논리)는 콜드메일이 합법적 관행. **콜드메일 인프라는 해외 고객 확보용으로 세팅**하는 것이 합리적.
  - 국내는 콜드메일 대신 **전화(사전동의 불필요한 일반 영업전화)·DM·방문·소개**가 주력.

## 2. 콜드콜 (전화영업)

### 2.1 벤치마크 [출처: SalesHive 2026, Focus Digital, Cleverly, Gong 데이터]

| 지표 | 평균 | 상위 |
|---|---|---|
| 연결률(Connect rate) | 3~10% (Gong 3억 통 분석 5.4%) | 13.3% |
| 통화→미팅 전환 | 2.3~2.5% (40~45통당 1미팅) | 5~8%+ |
| 대화→미팅 | 4.6% | 16.7% (엘리트) |
| 하루 통화 수 | 40~50통 (전체 활동 80~100) | – |
| 하루 실질 대화 | ~4.4건 | – |
| 월 미팅 | 15~21건 | – |
| 한 명에게 닿기까지 시도 | 평균 8회 | – |
| 최적 요일/시간 | 화~목, 10~11시 / 16~17시 (16~17시는 71% 더 효과) | – |

- **하루 80통 넘기면 전환율 2.8% → 1.9%로 하락** (개인화 상실).
- 연결률 10% 미만이면 스크립트가 아니라 **전화번호 데이터** 문제.
- 코칭 없으면 2.35%, 매일 코칭하면 9%까지 (약 4배).
- 5번째 후속까지 가는 영업자는 8%뿐 → 끈기 자체가 경쟁우위.
- 사전 리서치한 영업자가 일반 스크립트 대비 **56% 높은 전환** [출처: Callin.io].

**퍼널 [추정]**: 하루 50통 × 20영업일 = 1,000통/월 → 미팅 25건(2.5%) → 계약 5~8건(20~30%). 1인이 전화만 붙잡아도 월 5건은 이론상 가능. 현실은 리스트 품질·노쇼로 절반.

## 3. Loom 영상 감사(Audit) / "무료 광고 만들어드렸어요" 방식

### 3.1 프레임워크 [출처: ListKit "Trojan Horse Loom", Icemail, Weezly]

- 1차 메일/DM은 영상을 바로 보내지 않고 **"짧은 영상으로 설명드려도 될까요?"** 허락을 구한다 (스팸 필터·거부감 회피).
- 답장 오면 Loom 링크 + **썸네일 이미지 + 타임스탬프**("1:45 부분 보시면…") + 구체적 시간 제안.
- 영상 **3~5분**, 구조: 어젠다 → 발견한 문제/기회 → 실행 가능한 인사이트 → 부드러운 CTA("원하시면 통화로 더 설명"). **서비스·가격·패키지 언급 금지.**
- ListKit은 이 방식으로 "$10M+ 매출, 월 $100k+" 주장. 캠페인당 연 600건+ 긍정 답장 사례(Icemail). 정량 전환율은 출처마다 미공개.

### 3.2 "I made you a free ad" 변형 [통념 + 추정]
- 영상 감사(문제 지적) 대신 **완성된 광고/쇼츠 1개를 먼저 만들어 보낸다.** 사장님 입장에서 "지적"보다 "선물"이 심리적 저항이 낮다.
- 워크플로 [추정]: 리드 30개 선정 → 매장 사진/인스타에서 소재 확보 → 쇼츠 자동 생성(사용자 파이프라인) → 카톡/DM으로 전달 → 48시간 내 전화 → "이런 걸 매주 3개 올려드리는 게 저희 일" → 미팅.
- 하루 10~15개 제작·전송이면 주 50~75개, 답장 20~30%(개인화 DM 벤치마크) → 주 10~20 대화 → 미팅 3~6 → **첫 달 계약 2~4건** [추정].
- 무료 제작물은 **워터마크 + 저해상도** 또는 1개만 제공하고, 사용권은 계약 시 부여.

## 4. 소셜/메신저 아웃리치

### 4.1 LinkedIn [출처: Expandi 13.2M 데이터, Overloop, Belkins]
- 연결 수락률 **28.5%** (타겟팅 잘 하면 30~45%, 40% 이상은 고성과)
- 연결 요청 노트 답장률 **3.0%** → 2025.5~2026.4 사이 3.5%→2.2%로 **37% 하락**
- 메시지 답장률 **10.4%**, 기존 연결 대상 메신저 캠페인은 16.9% vs 템플릿 8.6%
- 400자 미만 메시지가 22% 더 높은 답장, 63%의 수락은 24시간 내
- 2번째 후속이 +4.05%p, 1번째 후속은 효과 미미
- 주당 연결 요청 상한 **300건**
- 발신자 직급/회사 규모는 수락률에 거의 영향 없음 (매니저나 CEO나 동일)
- **국내 적용**: 소상공인은 LinkedIn 안 씀. 스타트업/중견기업 마케팅 담당자·대표 타겟 B2B 대행에만 유효 [통념].

### 4.2 Instagram DM (해외) [출처: PhantomLeads, InfluenceFlow, ReplyRush]
- 신규 계정 하루 **10~15통** → 신뢰 쌓이면 20~25통. 신규 계정 50~100/일, 안정 계정 200/일이 플랫폼 상한선.
- 목표치: 오픈 70~85%, **답장 15~30%**, 대화→콜 **20~40%**
- 개인화 32% vs 복붙 18% 답장. 발송 시간 18~21시(수신자 시간대)
- 후속: D3 짧은 범프 → D5~7 관련 자료 공유 → D7~10 "마무리 메시지" → 3회 무응답 시 중단
- 피할 것: 팔로워 늘려준다는 막연한 약속, 자기소개 장문, 빈 머지태그, 상대 콘텐츠 비난, 포트폴리오 링크 무단 첨부

**DM 템플릿 5종 (원문 → 번역)** [출처: PhantomLeads]
1. 진심 칭찬: "Hey [name] - been following your content for a bit and I really like what you are doing with [specific]…" → "안녕하세요, {{매장명}} 피드 보고 있었는데 {{구체 콘텐츠}} 정말 좋더라고요…"
2. 관찰+인사이트: "…your [space] looks amazing. One thing I noticed is…" → "매장 분위기 너무 좋은데, 하나 눈에 띈 게…"
3. 공통 연결: "I noticed we both follow [mutual]…" → "저희 둘 다 {{공통 계정}} 팔로우하고 있더라고요…"
4. **가치 우선**: "I put together a quick [audit/mockup/content idea] for your page just for fun…" → "재미 삼아 {{매장명}} 용 릴스 하나 만들어봤는데 보내드려도 될까요?"
5. 결과 기반: "I just helped [similar business] go from [A] to [B]…" → "{{유사 업종}} 매장을 {{A}}에서 {{B}}로 만들었는데…"

### 4.3 국내 인스타 DM 영업 [통념 + 검색 결과 요약]
- 국내 소상공인·병원·학원·미용실·필라테스는 인스타가 사실상 대표 채널 → DM이 사장님께 직접 닿는 가장 짧은 경로.
- 답장률을 좌우하는 것: **프로필 신뢰**(실명·얼굴·포트폴리오 릴스 9개 이상), **첫 메시지 길이 3줄 이내**, **선물(샘플 영상) 첨부**.
- 사장님들은 "광고 대행 제안" DM을 하루에도 여러 개 받는다 → 대행사 티가 나는 첫 문장("안녕하세요 ○○마케팅입니다")은 즉시 무시됨. 매장 관찰로 시작.
- 두들(duudle) 등 국내 툴 글 요지: 광고 없이 문의 오게 하려면 **릴스로 "결과물"을 계속 노출 + DM은 상담 톤**.
- 인스타 정책상 자동화 DM은 계정 정지 위험, 수작업 하루 20~30통이 안전선 [통념].

### 4.4 카카오톡 채널 [출처: 카카오 비즈니스 채널 가이드/영업 정책 PDF, 카카오 사례]
- 카카오톡 채널은 **친구 추가(=동의)한 사람에게만** 메시지 발송 가능 → 콜드 아웃리치 채널이 아니라 **인바운드 상담·재접촉 채널**.
- 대행사 활용법: 명함/DM/전화 후 "카톡 채널 추가해주시면 샘플 보내드릴게요" → 채널 친구 = 옵트인 리드 → 이후 사례 소식·이벤트 메시지 합법 발송.
- 카카오 채널 대행(광고 대행업)은 카카오 영업 정책·정보통신망법 적용 대상. 채널 메시지에도 (광고) 표기·수신거부 규정 적용.
- 카카오 공식 사례: 채널로 단골 관리해 매출 500% 증가 소상공인 사례 → 이런 케이스를 **사장님 설득 자료**로 활용 가능.

### 4.5 네이버 카페 영업 (맘카페·자영업 카페) [통념]
- 자영업자 카페("아프니까 사장이다" 등)·맘카페는 **직접 홍보글은 강퇴/삭제**가 기본 규정. 우회 방법은 "정보성 글로 신뢰 쌓기 → 프로필/댓글로 문의 유도".
- 실무 패턴: (1) 등업 조건 충족 → (2) "요즘 릴스로 손님 늘리는 법" 같은 정보 글 주 2~3개 → (3) 쪽지/댓글 문의에 응대 → (4) 카페 운영진과 제휴(공식 협력업체·강의). 카페 규정을 반드시 먼저 읽고, 홍보 게시판이 따로 있으면 거기만 쓸 것.
- 맘카페는 병원·학원·키즈 업종 **의사결정자(엄마)**가 모여 있어 클라이언트 영업용이 아니라 **클라이언트의 마케팅 채널** 제안 소재로 더 유용.

### 4.6 당근 비즈프로필 [출처: business.daangn.com]
- 비즈프로필은 **무료 등록**, 광고는 디스플레이/검색 2종, "원하는 동네만" 타겟, 간편모드(소상공인)/전문가모드(마케터). 구체 CPC·반경 수치는 공개 페이지에 없음. 공식 대행사 파트너 프로그램 언급 없음.

## 9. 정부·공공 프로그램으로 돈 받기

### 9.1 구조 이해
정부 마케팅 지원 사업은 크게 두 유형이다 [추정 분류]:
1. **수행기관(공급기업) 등록형**: 정부가 소상공인/중소기업에 바우처(포인트)를 주고, 기업이 등록된 수행기관 중 골라서 쓴다. 대행사는 수행기관으로 등록되면 **정부 예산으로 정산**받는다. (수출바우처, 데이터바우처, 일부 지자체 온라인마케팅 지원)
2. **용역 입찰형**: 지자체/공단이 "홍보 용역" 자체를 입찰(나라장터 g2b)로 발주. 대행사가 직접 응찰. (예: "2026년 소상공인 전통시장 지원사업 종합홍보 용역", "한돈 온라인 소비활성화 대행사 선정")

### 9.2 소상공인 온라인판로 지원사업 [출처: bizinfo.go.kr, 판판대로, 한국중소벤처기업유통원]
- 중기부·소상공인시장진흥공단·중소벤처기업유통원이 운영. 지원 내용: 상품개선, **상세페이지 제작, 콘텐츠 제작, SNS 마케팅, 온라인 홍보**, 라이브커머스, 글로벌 쇼핑몰 입점, MD 상담회, 물류.
- **수행기관 모집 통합공고**는 매년 1월경(2025년은 1월 16일 공고). 세부 사업별 개별 공고(글로벌시장지원 수행기관, 글로벌쇼핑몰 활용 판매 지원 수행기관 등)가 뒤따름.
- 참여기업(소상공인) 모집은 연 2회 이상(2026년 1차·2차 공고 확인).
- 대행사 진입 경로 [추정]: (1) 통합공고 첨부 "세부관리지침"에서 수행기관 자격(법인·업력·전담인력·실적) 확인 → (2) 콘텐츠 제작/SNS 마케팅 분야 수행기관 신청 → (3) 선정 시 판판대로에 등재되어 소상공인이 선택. 1인 개인사업자는 자격 미달인 경우가 많아 **법인 설립 + 실적 2~3건**이 선행 조건인 경우가 흔함 [통념].

## 10. 세일즈 콜 → 제안 → 계약 → 온보딩

### 10.1 30분 디스커버리 콜 프레임 [출처: TirionForge, Hathawk, Seven Figure Agency]
| 단계 | 시간 | 핵심 |
|---|---|---|
| 1. 라포 & 사전 브리핑 확인 | 2분 | "{{목표}}가 있으시고 {{장애}}가 걸림돌이라고 들었는데 맞나요?" |
| 2. 확인 & 심화 | 8분 | 영향("일상 매출에 어떻게 영향?"), 시도한 것("지금까지 뭘 해보셨어요?"), 성공 기준("6개월 뒤 잘 되면 어떤 모습?") |
| 3. 솔루션 제시 | 10분 | 사례 1개 + 그들 상황 매핑. 기능 나열 금지 |
| 4. 반론 처리 | 5분 | 아래 10.2 |
| 5. 클로즈 & 다음 단계 | 5분 | 당일 계약서/인보이스, 첫 세션 날짜 확정 |

- 사전 브리핑 없이 20~25% → 사전 브리핑(AI 생성 포함) 시 **35~42%** 클로징.
- 예산·결정권자·시기는 **처음 15분 안에** 묻는다(끝에 물으면 늦음).
- 디스커버리→계약 전환 업계 평균 10~30%.
- 대응 분기: **즉시 진행** → 당일 계약서 발송 / **생각해보겠다** → 사례 첨부 요약 메일 + "{{요일}} 15분 후속 통화" 고정 / **부적합** → 다른 업체 소개.

### 10.2 반론 처리 스크립트 [출처: TirionForge, Seven Figure Agency 요약, 번역]
| 반론 | 응답 골자 | 한국어 예시 |
|---|---|---|
| "비싸요" | 목표 매출 대비 재구성 + 시스템의 지속 가치 | "지금 월 1,200이고 2,000 가고 싶다고 하셨죠. 800 차이인데 저희 비용은 월 80입니다. 한 달만 앞당겨도 본전이고, 만든 콘텐츠는 계약 끝나도 남습니다." |
| "생각해볼게요" | 무엇을? (비용/시기/방식) 특정 | "당연하죠. 혹시 걸리는 게 비용 쪽인지, 시작 시기인지, 방식인지 여쭤봐도 될까요?" |
| "전에 대행사한테 데였어요" | 인정 + 구체 차별점(보고 주기·해지 조건) | "그 얘기 진짜 많이 듣습니다. 그래서 저희는 위약금 없는 월 단위 계약이고, 매주 화요일 숫자 보고 드립니다." |
| "동업자/배우자랑 상의" | 요약 문서 제공 + 후속 날짜 고정 | "한 장짜리 요약 보내드릴게요. 목요일 오후 3시에 두 분 같이 10분 통화 가능하실까요?" |
| "다음 달부터" | 진짜 제약인지 회피인지 확인 + 지연 비용 수치화 | "다음 달 시작하면 성수기 4주를 놓치는데, 그 4주치 예약이 대략 얼마쯤 될까요?" |
| "직접 하면 되잖아요" [통념] | 시간 원가 계산 | "직접 하시면 주 5시간, 사장님 시급으로 월 100 넘습니다. 그 시간에 손님 한 테이블 더 받으시는 게 낫지 않을까요?" |

### 10.3 가격 앵커링 [출처: Priceva, InsideBE 요약 + 통념]
- 3단 가격표(예: 라이트 39만 / 스탠다드 79만 / 프리미엄 149만)에서 **프리미엄이 앵커**, 스탠다드가 실제 판매 목표. 앵커가 너무 높으면 역효과.
- 국내 소상공인 월 정액 현실 구간 [통념]: SNS 콘텐츠(쇼츠 8~12개+피드) 월 30~80만 원, 퍼포먼스 광고 대행 광고비의 10~20%(최소 대행비 30~50만 원), 병원/학원은 100~300만 원.
- 첫 계약은 **"3개월 파일럿, 1개월 단위 해지 가능"**으로 진입 장벽을 낮추고, 파일럿 종료 시 정가로 전환.

### 10.4 제안서 vs 견적서 (국내 관행) [출처: duudle 가이드, yesform, 데모데이 계약서 도구]
- **제안서**(3~10p, 설득: "왜 우리와"): 현황 진단 → 목표 → 전략 3가지 → 사례 → 일정 → 가격 범위 → 팀.
- **견적서**(1~2p, 확정: "무엇을 얼마에"): 필수 7항목 — ① "견적서" 표기 ② 양측 정보(사업자번호·견적번호·발행일) ③ 프로젝트 요약 2~3문장 ④ **항목별 단가**(총액만 쓰지 말 것) ⑤ 결제 조건(계약금 30~50% / 중도금 30% / 잔금 20~40%) ⑥ 유효기간 14일(대형 30일) ⑦ 추가 작업 기준("범위 외 작업은 별도 견적").
- 표기: **부가세 별도** 명시, 개인 프리랜서면 "3.3% 원천징수 별도/포함" 구분. 견적→계약 전환율 평균 6~10%.
- **광고대행 계약서 필수 조항**: 당사자 정보 / 매체·채널 / 총 광고 예산 + 대행 수수료율(디지털 10~20%, 퍼포먼스는 CPA·ROAS 연동 가능) 또는 고정 수수료 / **광고 소재 소유권·사용 허락 범위**(미기재 시 제작사 귀속 가능) / 성과 보고 주기·형식 / 계약 기간·해지 조건 / [권장 추가] 광고비 선입금·계정 소유(광고계정은 광고주 명의), 비밀유지, 손해배상 상한(대행비 1~3개월분), 자동연장 여부 명시(사장님들이 가장 경계하는 항목이므로 "자동연장 없음"을 세일즈 포인트로).
- 양식: 예스폼 광고대행 계약서(114613), 데모데이 무료 작성 도구.

### 10.5 온보딩 체크리스트 [통념 + 추정]
1. 계약서·견적서 서명, 계약금 입금 확인, 세금계산서 발행
2. 접근 권한: 인스타/페이스북 비즈니스 관리자 파트너 권한, 네이버 스마트플레이스 관리자 위임, 유튜브 채널 관리자, 광고계정(광고주 명의) 파트너 연결, 카카오 채널 관리자
3. 브랜드 키트: 로고/색/폰트, 금지 표현(의료광고법·학원법 등 업종 규제), 기존 소재 폴더
4. 킥오프 30분: 목표 KPI 1개, 보고 채널(카톡 그룹/주간 메일), 승인 프로세스(시안 승인 48h 룰), 촬영 일정
5. 첫 7일 안에 결과물 1개 게시("빠른 승리")
6. 주간 보고 템플릿: 게시 수 / 조회·도달 / 문의·예약 수 / 다음 주 계획 (커넥트리 주간 보고서 샘플 참고)
7. 30일 리뷰 콜 → 재계약/업셀

## 11. 실제 수치와 첫 고객 사례

### 11.1 해외 [출처: Josh Nelson(Seven Figure Agency) 블로그 요약, 검색 스니펫]
- SMMA 창업자가 특정 방법 실행 후 **23일 만에 첫 고객** 사례 언급.
- 월 $20k 미만 대행사의 1순위 질문은 항상 "고객 어떻게 더 얻나" → 답은 "단일 채널 의존 탈피, 예측 가능한 시스템".
- Reddit(r/agency, r/SMMA) 원문은 이번 세션에서 접근 불가(차단). 커뮤니티 통념 [통념]: 첫 고객까지 **평균 1~3개월**, 가장 흔한 첫 고객 경로는 ① 지인/전 직장 소개 ② 무료/할인 파일럿 ③ Upwork ④ 콜드 아웃리치 순. "포트폴리오 0" 상태에서는 2~3곳을 무료 또는 원가로 해주고 케이스 스터디를 만든 뒤 유료 전환하는 패턴이 가장 자주 보고됨.

### 11.2 국내 [출처: 브런치 @jennyjang93, 스레드 @donjalnam, 아이보스 스니펫]
- 브런치 "무자본 1인 마케팅 에이전시": 호주에서 1인으로 시작해 50개+ 고객사. 성공 조건 3가지 = **마케팅(연락 메일/메시지·블로그·PPC로 잠재고객 유치) + 판매(ROI 강조 클로징) + 서비스 제공(직접 또는 화이트라벨 아웃소싱)**. 전공·학벌 무관, "빠른 학습 곡선"만 중요.
- 스레드 "0원으로 1인 마케팅 대행사": 전문직·자영업자 매장을 대신 홍보하는 상생 구조. 고객 찾는 법·첫 계약·가격은 후속 편 예고(본편 미확보).
- 아이보스 커뮤니티 질문("광고대행사분들 영업 어떻게 하시나요")이 반복적으로 올라옴 = 국내에서도 영업이 1번 병목. 답변 요지: 콜영업·자료 뿌리기·소개·플랫폼 병행.
- 사장님 측 인식(동네홍보독학): 대행사 전화에 "상위노출 보장/리뷰 작업/자동연장/환불불가"를 경계 → **투명한 계약이 곧 영업 무기**.

### 11.3 포트폴리오 0에서 시작하는 현실 플랜 [추정]
| 주차 | 행동 | 목표 수치 |
|---|---|---|
| 1주 | 인스타 프로필 정비 + 자기 쇼츠 9개(자동 생성) + 케이스용 매장 3곳 선정(지인/단골/집 근처) → 무료 or 원가 3개월 제안 | 무료 클라이언트 2~3 |
| 2~4주 | 매일 무료 릴스 10개 제작·DM/카톡 전송 + 010 콜 20통 | 대화 40, 미팅 8, 유료 계약 1~2 |
| 5~8주 | 무료 클라이언트 전/후 수치 확보 → 케이스 페이지 3개 + 쇼츠 "실험 결과" 콘텐츠 | 인바운드 문의 주 2~5 |
| 9~12주 | 세무사·인테리어·간판 제휴 5곳 + 지자체 지원사업 참여기업 대상 패키지 영업 | 월 신규 3~5, 월 정액 150~300만 원 |
| 4~6개월 | 수출바우처/온라인판로 수행기관 등록 준비(법인·실적), 해외 콜드메일 인프라(도메인 5개) 워밍업 시작 | 해외 파일럿 1~2 |

**비용 [추정]**: 1~3개월차 총 현금 지출 30만 원 이하(도메인·툴 제외). 콜드메일 인프라 추가 시 월 $150~200.

## 12. 이 사용자(쇼츠/블로그 자동 생성 보유)에게 특화된 권고 [추정]

1. **"선물형 아웃리치"를 표준 프로세스로**: 리드 1개당 샘플 쇼츠 1개 자동 생성 → DM/카톡 → 전화. 해외 벤치마크(개인화 DM 32%, 가치 우선 템플릿)와 국내 정서(선물·관찰·투명 계약)가 모두 이 방식을 지지.
2. **국내 콜드메일 대량 발송은 하지 말 것** — 정보통신망법 사전동의 원칙, 과태료 3천만 원 이하. 이메일은 소량 1:1 + 형식 요건 준수, 대량 인프라는 해외 전용.
3. **콘텐츠 인바운드는 사장님 검색어 기준으로**: "{{업종}} {{지역}} 릴스 예약 늘리기" 류. 각 콘텐츠 CTA는 "무료 릴스 1개".
4. **소개 파이프**는 세무사·인테리어·간판. 소개비 10%, 12개월 상한, 서면.
5. **정부 사업**은 6개월 뒤 목표: 온라인판로 수행기관·수출바우처(영상 콘텐츠 카테고리). 그 전에는 지자체 지원금(하남시 150만 원 등) 받는 **참여기업**을 상대로 패키지 영업.
6. **계약은 사장님 공포를 역이용**: "자동연장 없음 · 월 단위 해지 · 광고계정 사장님 명의 · 매주 숫자 보고"를 첫 화면에 명시.
7. **측정**: 채널별 (보낸 수 → 답장 → 미팅 → 계약) 4단 퍼널을 주간으로 기록. 답장률 15% 미만이면 메시지, 미팅→계약 20% 미만이면 콜 스크립트·가격 문제.
