**서비스별 리테이너 벤치마크 (Gigradar 2026)** [3]

| 서비스 | 바닥 | 전형 | 프리미엄 |
|---|---|---|---|
| SEO | $1.5k~2.5k | $4k~8k | $12k~25k+ |
| PPC(광고운영) | $1.5k | $2k~4k (또는 광고비의 10~20%) | $10k+ |
| 콘텐츠 | $1k~2.5k | $5k~15k | $15k+ |
| 디자인 | $2k~4k | $6k~15k | $15k+ |

- 단, **현실 분포는 훨씬 낮다**: SEO 대행사의 64%가 월 $1,000 미만을 청구하고, 60%가 시간당 $100 미만. 가장 흔한 구간은 **월 $500~1,000** [4]. 즉 "벤치마크 표"는 상위 대행사 기준이고, 시장의 다수는 저가 경쟁 중.
- 시간당 평균: 디지털 대행 ~$138/h, PPC ~$152/h [4].
- 대행사의 ~85%가 리테이너 중심으로 운영 [4].

**리테이너 가격 산정 공식 (Gigradar)** [3]
- `시간당 요율 × 월 예상 시간 × 0.85~0.90` (장기 계약 할인 10~15%)
- 예: $200/h × 20h × 0.875 ≈ $3,500/월
- 범위확장 버퍼 10~20% 시간 추가 → 23h × $200 × 0.85 ≈ $3,910
- **딜리버리 마진 55~60% 이상** 유지(오버헤드 30% 가정 시 순이익 25%). "이행 원가가 요금의 60%를 넘으면 가격을 올리거나 자동화하라. 제3의 길은 없다."
- 청구 요율 ≈ 인건비 시간당 원가의 3배 (예: $54/h 원가 → $175/h 청구)

## 2. 광고비 % 모델 + 네이버 공식대행사 구조

### 2-1. 해외: 광고비 대비 %

| 항목 | 수치 | 출처 |
|---|---|---|
| 표준 요율 | 광고비의 **10~20%** (업계 표준 15~20%) | [15][16] |
| 최소 관리비 | **$500~800/월** | [15][16] |
| 플랫 요금 대안 | 소상공인 $500~750, 중형 $1,500~2,500 | [15] |
| 하이브리드 | 기본 $1,000 + 초과분 5~10% | [15][16] |
| 셋업비 | $500~2,500 | [16] |
| 랜딩페이지 | 페이지당 $500~2,000 | [16] |
| 예시 | 15% × $5,000 = $750, 15% × $10,000 = $1,500 | [16] |
| % 모델 손익분기 | 월 광고비 **$8,000~12,000 미만**이면 %만으로는 대행사가 인력을 붙일 수 없음 | [17] |

- **광고비는 항상 플랫폼이 광고주에게 직접 청구** — 관리비에 포함되지 않는다. 예: 리테이너 $4,000 + 광고비 $15,000 = 총 $19,000 [17]. → 대행사 카드로 광고비를 태우지 않는 것이 현금흐름·세금·분쟁 방지의 핵심(§10-6).
- 이해충돌: 광고비가 늘수록 대행사 수입이 늘어 "예산 증액 유도" 인센티브 발생 → 최근 플랫/하이브리드로 이동 중 [15].

### 2-2. 국내: 네이버 공식대행사 모델 (정확한 구조)

| 항목 | 내용 | 출처 |
|---|---|---|
| 광고주 부담 수수료 | **0원** | [18][19][20] |
| 대행사 수입 | 광고주 **유상 소진액의 15%를 네이버가 대행사에 지급** | [18][19] |
| 예시 | 월 광고비 100만 원 → 네이버가 대행사에 15만 원 지급 | [18] |
| 광고주가 잃는 것 | 직접 운영 시 받는 광고비 5% 비즈쿠폰 소멸 | [18] |
| 3단 구조 | ① 공식 파트너사(네이버 직계약) ② 공식 대대행사/재대행사(파트너사와 계약) ③ 일반 운영 대행사(공식 관계 없음, 별도 수수료 청구 가능) | [20] |
| 재대행 수수료 | 공식대행사가 1~4% 떼고 **11~14%**를 대대행사에 전달 | [21] |
| 직원 인센티브 | 기본급 + 담당 소진액의 5~8% → 광고주 월 300만 원 소진 시 직원 15~24만 원 | [19] |
| 매체 일반 | 국내 매체(네이버·GFA·카카오 등)는 대행사에 광고비의 15~20% 지급이 일반적 | [21][22] |
| 토스애즈 사례 | 사전 협의 요율, `월 실제 집행 광고비 × 요율`, 토스→에이전시 역발행 세금계산서(매월 5일), 익익월 10일 입금 | [23] |
| 데이블 사례 | 대행사 통합계정 선충전(최소 100만 원, VAT별도), 데이블→대행사 세금계산서 발행 | [24] |

**구조적 함의**
- 대행사 수입 = 소진액 × 15% 이므로 **광고주 1곳당 월 광고비 100만 원이면 수입 15만 원** — 사람 한 명 붙이면 무조건 적자. 그래서 (a) 공식대행사는 소액 광고주를 신입에게 몰아주거나, (b) 소진액 늘리기 영업에 집중하거나, (c) 별도 "관리비"를 붙인다 [19][22].
- 린치핀 칼럼: "매출 목표 미달 시 수수료 삭감 → 신규 영업만 쫓는 직원 양산" → 대행(매체 수수료)과 기획(컨설팅 비용)을 분리하는 모델 제안 [22].
- 아이보스에 "네이버가 15% 대행수수료를 폐지하려 한다"는 논의 스레드가 존재(2020년대 초). 접근 불가(403)로 내용 미확인 — 요율 정책 변동 리스크는 존재 [25].
- 공정위는 2025년 11월 소상공인 기만 광고대행 8개 업체 수사의뢰, 연간 33개 업체. 네이버 광고주센터 사기 체크리스트: **월정액제 제안·상위노출 보장·별도 대행수수료 요구·과도한 위약금** [13].

### 2-3. 장단점

| 장점 | 단점 |

| 변형 | 구조 | 대행사 마진 |
|---|---|---|
| Pay-per-lead | 광고비 대행사 부담, 검증 리드만 판매 | (판매가 − 광고 CPL − 검증 인건비). 예: 광고 CPL 2만 원 → 4.5만 원 판매 = 55% |
| Pay-per-appointment | 예약 확정 건만 과금(리드의 2~3배 가격) | 콜센터/자동화 필요 |
| Rev-share | 매출의 10~30% | 랭크앤렌트에서 10~15% 관행 [31] |
| CPA 제휴 아비트라지 | 오퍼 CPA − 트래픽 비용 | §9 참조 |
| 국내 성과보장형 상위노출 | "OO동 치과 5위 이내 노출 시 청구" | 키워드당 10만~50만 원 [7][32] |

- 성과형 이탈률은 연 33%, 평균 계약 30개월 — 리테이너(18%, 56개월)보다 나쁘지만 프로젝트형(42%)보다 낫다 [14].
- 함정: "리드 단가만 보면 실패" — 업종 객단가·전환율 기준으로 적정 CPL을 역산해야 한다 [30]. 리드 품질 분쟁(중복·허위)은 반드시 계약서에 검증 기준 명시.

### 12-3. 권장 조합(3단계)

**1단계(0~3개월): 프로덕타이즈드 콘텐츠 구독**
- 상품: "월 12편 쇼츠 + 월 8편 블로그 + 월 리포트" **월 69만~99만 원**, 3개월 최소, 선불. 시장가(쇼츠 4만×12 + 블로그 5만×8 = 88만 원) 대비 정기계약 할인 관행(10~30%)에 부합 [7][11].
- 원가: 파이프라인 API·TTS·렌더 편당 2천~5천 원 + 검수 15분 → 매출총이익 85%+.
- 목표: 10~13 고객 → 월 700만~1,300만 원(§10-3). 1인 지원 한계(10~15) 안.
- 채널: 크몽(실효 21.7% = CAC로 간주, 마케팅 링크로 0.91%까지 절감) [39][40] + 자체 쇼츠 채널을 포트폴리오로.
- 계약: 광고비는 고객 계정, 관리비 선불, 세금계산서(일반과세) — §10-4/§11.

**2단계(3~9개월): 성과형 상향판매**
- 구독 고객 중 병원·학원·시술에 "DB당 과금" 옵션 추가 (국내 DB 5천~5만 원, 병원 4.5만 원 사례) [28][29]. 자체 블로그·쇼츠 트래픽으로 CPL을 낮춰 마진 50%+.
- 리드 정의·중복 기준·정산 주기를 계약에 명시(§11-1).

**3단계(6~12개월): 자산화 — 랭크앤렌트 국내판 + 커뮤니티**
- 파이프라인으로 지역×업종 키워드 블로그/사이트를 대량 생성 → 상위노출 키워드를 **키워드당 월 10만~50만 원**에 임대(국내 성과보장형 단가) [7], 해외 니치는 사이트당 $500~3,000 [31][33].
- 노하우를 유료 커뮤니티/강의로 전환(Skool $99/월 정액, 수익 100% 수취) [49] → 대행 이탈 완충.

**하지 말 것(근거)**
- 월 30만 원 저가 리테이너 34개 모으기: 지원 부담이 1인 한계의 2~3배 [45].
- 광고비 대납: 매출 과대계상·부가세 선납·미수 리스크 [24][64].
- "상위노출 보장 월정액": 공정위·네이버 사기 체크리스트 항목 [13].
- 광고비 % 단독: 월 광고비 300만 원 광고주로는 45만 원, 인건비 회수 불가 [19].
