# 17. 콘텐츠 상품 제작 규격 — 릴스/쇼츠 · 네이버 블로그 · 플레이스 소식

> 작성 2026-08-27. 대상: 솔로 운영자가 파는 "로컬 콘텐츠 구독"(월 릴스/쇼츠 + 네이버 블로그 + 플레이스 소식).
> 목적 ① seo-engine 파이프라인을 로컬 비즈니스용으로 설정하는 기준서 ② 클라이언트에게 건네는 샘플·검수 기준.
> 근거 표기: `[공식]` = 플랫폼·법령 공식 문서에서 확인, `[업계]` = 국내 마케터 커뮤니티·컨설팅 글, `[일반]` = 일반 지식(본 세션에서 원문 재확인 못함, 착수 전 1회 확인 권장).

## 0. 파이프라인 역량 요약 (seo-engine, 2026-08 기준)

1. 구조: `수집 → 키워드 → 주제(Topic) → 생성(Article) → 변환본(ArticleVariant, 채널별) → 발행 + 수익주입 → 성과(Metric)`. 블로그와 쇼츠가 같은 Article 테이블을 `contentType=post|shorts` 로 공유한다.
2. 쇼츠 대본은 AI(`shorts_script`/`shorts_hook`/`shorts_caption` 프롬프트)가 `hook/develop/proof/cta` 4비트 + 컷 구성으로 생성한다. 훅 유형 실측 데이터(`sourcing:analyze`)가 프롬프트에 들어간다.
3. 렌더(`shorts:render`)는 로컬 워커: 컷별 소재 scale+pad → satori+resvg 한글 자막 PNG overlay → concat → **1080×1920 / h264 / 30fps**. 소재 없는 컷은 단색 배경으로 폴백(초벌 확인용). **현재 무음(`-an`) — TTS·BGM 합성은 미구현.**
4. 업로드(`shorts:upload`)는 Supabase Storage `shorts` 버킷에 직접 올리고 앱에는 URL만 등록. 50MB 상한.
5. 발행 어댑터: 유튜브(Data API resumable, 하루 약 6건 쿼터), 인스타 릴스(Graph API `REELS` 컨테이너 + 인코딩 폴링). 댓글 작성까지 자동, **댓글 고정은 수동**.
6. 발행 게이트: `variantBlockers()` 한 곳에서 영상 URL·대가성 문구·채널 연결을 판정. 대가성 문구(`COUPANG_DISCLOSURE`)가 설명란/고정댓글에 없으면 발행 차단.
7. 소재 저작권 가드: `Product.assetSource`/`assetLicense`(seller_provided|stock|own|ai) NOT NULL. 출처 없으면 등록 불가.
8. 블로그 생성은 로컬 `claude -p` CLI 전용(글 1편 ≈ 3.5분, CLI 4~5회). 본문 링크 실검증(`sanitizeLinks`), 1,500자 미만 발행 차단, 근거 없는 주제 자동 발행 금지.
9. 채널: 사이트·블로그스팟·네이버·티스토리·인스타(카드뉴스 수동)·유튜브. 수익주입기: 애드센스·애드포스트·타불라·카카오·쿠팡(설명란/고정댓글 블록).
10. 관리자 포탈 `/blog/*`, `/shorts/*` 분리. 성과는 Phase 1 수기 입력.

### 1.2 길이: 7~15초 vs 30초

| 길이 | 언제 | 알고리즘 관점 | 파이프라인 |

### 1.3 훅 3초 규칙

- 0.0~0.5초: 첫 프레임에 **훅 자막 + 가장 자극적인 컷**(완성된 음식, 시술 결과(비의료), 가격 숫자). 로고·인트로 금지.
- 0.5~3초: 훅 문장 낭독(TTS) 또는 자막만. 3초 안에 "이 영상이 나에게 왜 필요한지"가 나와야 함.
- 3~10초: 본론(develop/proof). 컷 길이 2~4초, 같은 앵글 4초 이상 금지.
- 마지막 2~3초: CTA 화면(1.4).
- 파이프라인 훅 유형 실측(37건 중앙값): 충격사실 103만 > 문제제기 90만 > 질문형 65만 > 결과선공개 56만. 로컬 매장은 **"결과선공개 + 가격/장소 정보"** 조합이 안전.

### 1.4 CTA 화면 규격

- 길이 2~3초, 화면 중앙(안전영역 안: y 270~1250).
- 3줄 고정: ① 행동(예약/방문/저장) ② 방법(프로필 링크 · 네이버 "○○역 △△" 검색 · 전화) ③ 위치 한 줄(역명+도보 분).
- 예: `저장해두고 이번 주말에 오세요 / 네이버에 "망원 소금빵집" / 망원역 2번 출구 도보 3분`
- 공유·DM 전송을 유도하는 CTA를 우선("같이 갈 사람한테 보내기") — 공유(reshare)가 릴스 1순위 예측 신호 `[공식 2023]`. 2025년 이후 Mosseri 가 공개적으로 "시청 시간·도달당 좋아요·**도달당 전송(sends per reach)**" 3가지를 핵심으로 언급 `[일반 — 2025-01 릴 발언, 본 세션 원문 미확인]`.

### 1.6 해시태그 · 위치 태그 · 캡션

- 해시태그 **3~5개**: `#지역+업종`(#망원동카페) 1~2개 + `#업종`(#소금빵) 1개 + `#상황`(#망원데이트) 1개 + 브랜드 1개. 20개 도배 금지(텍스트 위주 게시물로 판정 위험).
- 위치 태그: 인스타 게시 시 **플레이스명과 동일한 위치 태그** 필수(로컬 탐색 노출). 유튜브는 제목·설명에 "○○역" 텍스트로.
- 캡션 1줄 = 훅 반복 + 2줄 = 정보(가격·위치·영업시간) + CTA. 인스타 캡션 첫 44자 안에 핵심(광고 가이드 권장 길이 `[공식]`).
- 유튜브 제목 100자 이내 `[공식]`, 제목에 `#Shorts` 는 선택(9:16 세로+3분 이하면 자동 분류).

### 1.7 발행 시간·빈도

- 업로드 시간(국내 로컬 업종 `[업계]`): 식당·카페 **11:00~12:00, 17:30~19:00**(식사 결정 직전), 뷰티·헬스 **20:00~22:00**, 학원·병원 **12:00~13:00, 21:00**. 첫 2주는 시간대 A/B 후 인사이트로 고정.
- 빈도: STANDARD 주 2편, DELUXE 주 3편, PREMIUM 주 5편. 하루 2편 이상 몰아 올리지 않는다. 유튜브 쿼터는 클라이언트 합산 하루 6건이므로 클라이언트 10곳부터는 Google Cloud 쿼터 증설 신청 또는 사장님 계정 수동 업로드 병행.
- 인스타·유튜브 동시 발행 시 **워터마크 없는 원본 mp4** 를 각각 업로드(크로스 포스팅 감점 회피).

## 9. 샘플 릴스 "선물" 제작 규격 (영업용)

목적: 콜드 DM 단계에서 "이미 만들어 둔 15초 릴스"를 보여줘 답장률을 올린다. 입력은 공개 정보만.

### 9.1 입력
- 플레이스 공개 사진 3장(대표 사진·메뉴·매장) + 공개 리뷰 1개(작성자 익명화, 본문 40자 이내 발췌) + 업체명·역명·대표 메뉴/서비스 1개.
- **주의**: 플레이스 사진은 업주가 올린 것만 사용(방문자 리뷰 사진 사용 금지 — 제3자 저작물). 샘플은 **비공개 전송용**이며 업로드·광고 집행 금지. 계약 후 사장님 제공 원본으로 재제작.

### 9.2 출력
- 15초, 1080×1920, 30fps, H.264, 무음 또는 로열티 프리 BGM(TTS 선택).
- 반투명 워터마크 `SAMPLE · {대행사명}` 우상단(안전영역 밖 아님: y 300 부근, 불투명도 40%) + 마지막 2초 "정식 제작 시 워터마크 제거" 카드.
- 파일 8MB 이하(DM 전송 한도 여유), 파일명 `{YYMM}_{업체명}_sample_v1.mp4`.

### 9.3 자동 구성 (컷 4개)
| 컷 | 초 | 소재 | 자막(자동 생성) |
|---|---|---|---|
| 1 훅 | 0~3 | 대표 사진 Ken Burns 줌인 | 훅 50개 중 업종 매칭 1개 (예: "{역명}에서 {메뉴} 찾으면 여기") |
| 2 증거 | 3~8 | 메뉴/서비스 사진 팬 | "{메뉴} {가격}원" (가격은 플레이스 공개 메뉴에 있을 때만) |
| 3 리뷰 | 8~12 | 매장 사진 + 리뷰 카드 오버레이 | "\"{리뷰 발췌}\" — 방문자 리뷰" |
| 4 CTA | 12~15 | 단색 배경 + 로고 없이 텍스트 | "네이버에 '{업체명}' 검색 / {역명} 도보 {n}분" |

### 9.4 파이프라인 매핑
- `Client` 레코드 생성(`assetLicense=place_public_owner`, 출처 URL = 플레이스 URL) → `Article(contentType=shorts, hookType=자동)` → `storyboardJson` 4컷 자동 채움 → `shorts:render` → 워터마크 필터(`drawbox`+PNG overlay) → 로컬 저장(Storage 업로드 안 함, 발행 게이트 진입 안 함).
- 배치: 하루 20개 타깃 × 편당 렌더 약 40초 = 15분. 사람 검수 2분/편(사진 부적절·오타).
- DM 규격: 영상 첨부 + 3줄("사장님 매장 사진으로 만들어본 15초 샘플입니다 / 워터마크 없이 쓰셔도 되게 정식 버전 드릴 수 있어요 / 답장 주시면 어떤 구성이 좋을지 같이 봐드릴게요"). 정보통신망법상 광고성 정보 전송 규정(사업자 공개 연락처·야간 금지 21~08시·수신거부 안내) 준수 — 상세는 client-acquisition 플레이북.

### 9.5 샘플 품질 최소선
- 사진 3장 중 1장이라도 해상도 720px 미만이면 제작 보류(흐린 샘플은 역효과).
- 리뷰 발췌에 개인 식별 정보·부정 문구 없음.
- 훅에 가격·효과 단정 없음(공개 정보 밖 주장 금지).
