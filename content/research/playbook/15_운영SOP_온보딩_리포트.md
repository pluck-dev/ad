### 1.2 킥오프 미팅 아젠다 (30분, 매장 방문 권장)

1. (3분) 오늘 목표: "3개월 뒤 무엇이 달라져 있으면 성공인가"를 사장님 말로 한 문장 — 노션 최상단에 그대로 적는다. 예: "평일 저녁 예약 2팀 → 5팀".
2. (5분) 상품 범위 재확인: 월 릴스 N개, 블로그 N편, 플레이스 관리, 광고 예산(사장님 카드 직접 결제) — 계약서 §범위와 동일한지 구두 확인.
3. (5분) 금지 표현·민감 사항: 의료·미용은 비포애프터 불가, 학원은 합격률·성적 보장 표현 불가, 음식점은 "최고·1위·유일" 금지. 사장님이 절대 싫어하는 톤(예: "반말 자막 싫음") 기록.
4. (5분) 소재 소스 결정: 기존 사진 폴더 있는지, 사장님이 주 1회 폰 촬영 가능한지, 얼굴 노출 OK인지, 직원 초상권 동의는 받았는지.
5. (7분) **현장 촬영**: 촬영 가이드(§1.5-2)대로 10초 클립 5개 + 정면 외관·메뉴판·베스트 메뉴 3장을 내 폰과 사장님 폰으로 찍는다.
6. (3분) 운영 규칙 합의: 월요일 승인 요청 → 48시간 무응답 시 자동 승인, 수정 월 2회 무료, 금요일 3줄 리포트, 월초 월간 리포트. 결제일·결제 방식 재확인.
7. (2분) 권한 6종 안내 — "지금 폰에서 같이 해드릴게요" (인스타 협업 요청·플레이스 관리자 초대는 현장에서 끝내는 게 가장 빠르다).

### 1.3 자료 수집 폼 (구글폼 30문항)

**A. 브랜드 (1~6)**
1. 상호명(정확한 표기, 영문 표기 있으면 함께)
2. 업종·주력 서비스 한 줄 (예: "수제버거 전문, 포장·배달 병행")
3. 창업 연도·대표 이력 중 손님에게 말해도 되는 것
4. 우리 가게를 한 문장으로 소개한다면?
5. 단골이 우리를 좋아하는 이유 3가지 (사장님 생각)
6. 절대 하고 싶지 않은 이미지·톤 (예: 싸구려, 과장, 반말)

**B. 타깃·상권 (7~11)**
7. 주 고객층(연령·성별·직업·거주/직장 여부)
8. 가장 늘리고 싶은 손님 유형 (예: 평일 점심 직장인, 주말 가족)
9. 손님이 우리를 찾을 때 검색할 것 같은 키워드 5개
10. 상권 반경(도보 10분 / 차 15분 / 온라인 전국 등)
11. 성수기·비수기·요일별 패턴

**C. 메뉴/시술/과정·가격 (12~17)**
12. 대표 메뉴(시술·과정) 3개와 가격
13. 마진 좋고 밀고 싶은 메뉴(시술) 1~2개
14. 노출하면 안 되는 가격이나 조건 (예: 이벤트가는 매장 문의만)
15. 현재 진행 중이거나 예정된 이벤트·프로모션
16. 예약/주문 경로(네이버 예약·전화·캐치테이블·앱 등)
17. 영업시간·휴무·주차·포장·배달 정보 (플레이스와 동일한지 확인)

**D. 금지 표현·법적 (18~21)**
18. 업종상 쓰면 안 되는 표현(의료광고 심의 여부, 학원 광고 규정 등)을 알고 있는 범위에서
19. 손님·직원 얼굴 노출 가능 여부, 직원 초상권 동의 여부
20. 매장 내 음악·캐릭터·타 브랜드 로고 등 저작권 이슈 가능성
21. 과거 광고·리뷰 관련 민원·분쟁 이력

**E. 경쟁사·레퍼런스 (22~24)**
22. 같은 상권 경쟁 매장 3곳(플레이스 링크)
23. "이렇게 하고 싶다" 싶은 타 지역·타 업종 인스타 계정 2개
24. "이건 절대 싫다" 싶은 계정·콘텐츠 예 1개

**F. 사진·촬영 (25~28)**
25. 기존 사진·영상 보관 위치(폰·구글포토·드라이브·과거 대행사)
26. 주 1회 10초 클립 5개 폰 촬영 가능 여부(가능 / 격주 / 불가능)
27. 촬영 가능한 요일·시간대(손님 적을 때)
28. 사장님 본인 출연 가능 여부(얼굴 / 손·목소리만 / 불가)

**G. 계정·운영 (29~30)**
29. 보유 계정 목록: 플레이스·인스타·페이스북 페이지·네이버 블로그·유튜브·카카오 채널·홈페이지·GA4 — 아이디(비밀번호 아님)와 관리자 여부
30. 연락 선호: 카톡 / 전화 / 문자, 연락 가능 시간대, 승인 담당자(사장님 외 직원이면 이름)

### 1.5 촬영·소재 수급

**1) 소재 소스 3층 구조**
- 1층(필수, 월 1회 이상): 사장님/직원 폰 촬영 현장 클립 — 플랫폼 노출·신뢰의 핵심. 완전 생성형만 쓰면 네이버·메타 모두 약하다(raw/07 §7.6).
- 2층: 내가 분기 1회 방문 촬영(30분, 폰 + 짐벌). 갱신용 외관·메뉴·시술 과정 B-roll 30컷.
- 3층: 파이프라인 생성물(자막·나레이션·템플릿·AI B-roll)로 1·2층 소스를 주 3~5개 릴스, 월 4편 블로그로 변환.

**2) 사장님 폰 촬영 가이드 1장 (그대로 인쇄·카톡 전송)**

```
[ 10초 클립 5개면 충분합니다 ]
1. 조명: 창가·낮 시간. 형광등 아래는 얼굴이 초록빛 → 창 쪽을 등지지 말고 마주보기.
2. 세로로 촬영(9:16). 폰을 두 손으로, 팔꿈치를 몸에 붙이고. 줌 금지, 발로 다가가기.
```

## 2. 주간 운영 루틴

### 2.1 요일별 (클라이언트 1곳 기준)

| 요일 | 작업 | 시간 |
|---|---|---|
| 월 | 파이프라인 결과물 검수(§2.3) → 승인 페이지 갱신 → 카톡 "이번 주 승인 요청" 발송(§3). 광고 지난주 성과 스캔(지출·CPL·빈도) | 40분 |
| 화 | 승인된 릴스 1 발행(예약 게시), 플레이스 리뷰 답글·소식 1개, 광고 소재 교체/킬룰 적용 | 20분 |
| 수 | 릴스 2 발행, 블로그 1편 발행(격주면 격주), 인스타 댓글·DM 확인(예약 문의는 사장님에게 즉시 전달) | 20분 |

- 10곳이면 주 15~20시간. 개발자 본업과 병행 가능한 상한은 **10곳** 전후. 그 이상은 검수·응대 자동화 없이는 품질이 무너진다(raw/01 §6-1: "분석가 1명에 15개 이상 계정은 무리").
- 클라이언트별 작업은 요일 축으로 묶지 말고 **작업 유형 축으로 배치**(월요일 오전에 10곳 검수를 한 번에) — 컨텍스트 스위칭이 가장 큰 시간 낭비다.

### 2.2 시간 초과 신호와 대응
- 한 클라이언트가 주 3시간을 넘기면: ① 수정 요청 횟수 확인(월 2회 초과 → 유료 안내) ② 소재 소스 미수령으로 내가 대체 소재를 만들고 있는지 ③ 카톡 응대가 승인 외로 확장됐는지. 세 가지 중 하나면 §3·§6 정책 문구로 정리.

## 3. 승인 워크플로

### 3.1 구조
- **승인 장소**: 노션 클라이언트 페이지 안의 "이번 주 승인" 데이터베이스(공개 링크, 게스트 로그인 없이 열람). 카드 = 콘텐츠 1개(썸네일·캡션·발행 예정일·상태).
- **알림 통로**: 카카오톡 채널 1:1 채팅(사장님이 가장 확실히 보는 곳). 노션 링크 하나 + 요약 3줄.
- **응답 방식**: 카톡에 "OK" 또는 "2번 문구 수정: ___" 만 받는다. 노션 댓글은 안 다는 사장님이 대부분이므로 카톡 답을 내가 노션에 옮겨 적는다.
- 구글시트 대안: 노션이 부담스러운 사장님은 시트 1장(열: 날짜·채널·미리보기 링크·캡션·승인란 O/X·메모). 링크만 바꾸고 프로세스는 동일.

### 3.2 월요일 승인 요청 카톡 (템플릿)

```
[△△ 이번 주 콘텐츠 승인 요청] 8/31(월)
릴스 3개, 블로그 1편, 플레이스 소식 1개입니다.
▶ 보기: (노션 링크)
- 릴스1 "○○동 점심 웨이팅 없는 시간" (수 발행)
- 릴스2 사장님 한마디 컷 (금 발행)
- 블로그 "△△ 주차·포장 가이드" (목 발행)
수정 없으면 "OK" 한 마디면 됩니다. 9/2(수) 12시까지 답이 없으면 계약대로 자동 승인되어 예정일에 나갑니다.
```

### 3.3 규칙 (계약서 조항과 동일 문구)
- **48시간 무응답 자동 승인**: "회사가 승인 요청을 발송한 시점부터 48시간(영업일 기준) 내 클라이언트의 회신이 없을 경우 해당 콘텐츠는 승인된 것으로 간주하며, 회사는 예정일에 발행할 수 있다. 발행 후 클라이언트 요청 시 즉시 비공개 처리하되 이는 수정 횟수에 산입한다."
- **수정 횟수**: "콘텐츠 수정은 월 2회(콘텐츠 건수 무관, 요청 회차 기준) 무료이며, 초과분은 회당 3만원 또는 다음 달 콘텐츠 1개 차감 중 클라이언트 선택." 사실 오류·법적 문제로 인한 수정은 횟수에 넣지 않는다(내 책임).
- **긴급 발행 정지**: 사장님은 언제든 "내려주세요" 가능, 나는 2시간 내 비공개. 대신 이유를 노션에 기록(반복되면 톤 가이드 재정의).
- **승인 담당자 1명**: 사장님 + 직원 여러 명이 각각 다른 말을 하면 진행 불가. 폼 30번 문항의 담당자 1명만 유효.

### 3.4 수정 요청을 받았을 때
1. 요청 원문을 노션 카드에 그대로 붙임(해석하지 않음).
2. 수정본은 24시간 내, 카톡으로 "수정했습니다 (링크). 이번 달 수정 1/2회 사용" 표기.
3. 같은 종류의 수정이 2회 반복되면 톤 가이드(§1.2-3)에 규칙 추가 → 파이프라인 프롬프트에 반영.

### 4.4 Looker Studio 자동화 구성 (무료 우선)

**확인된 사실**: Looker Studio의 구글 제작 커넥터(Google Sheets·GA4·Google Ads·YouTube·BigQuery 등)는 무료이며, 파트너/커뮤니티 커넥터는 개발자가 과금할 수 있다(Looker Studio 공식 문서). 메타·네이버·인스타 인사이트를 직접 연결하는 무료 공식 커넥터는 없다. Looker Studio Pro는 raw/07 §5.1 기준 유저·프로젝트당 월 $9(예약 발송 한도 확대) — 1인 운영에서는 불필요.

**구성(개발자 방식, 월 0원)**
1. **데이터 허브 = 구글시트 1개/클라이언트** (탭: place, insta, blog, ads, notes). 열 규격 고정: `date, client, channel, metric, value`.
2. **적재**
   - 메타 광고: Marketing API(시스템 사용자 토큰, 사장님 BM에서 파트너 권한으로 발급) → n8n 스케줄 노드 → 시트. 일 1회.
   - 인스타 인사이트: Instagram Graph API(프로페셔널 계정 + 페이지 연결 필요) → 도달·프로필 방문·팔로워 → 시트. 일 1회.
   - 네이버 블로그·플레이스: 공식 API 없음 → 월초 **수동 입력 5분**(플레이스 통계 화면 보고 6개 숫자 입력) 또는 플레이스 통계 CSV 다운로드가 제공되는 경우 업로드. 자동 크롤링은 약관·계정 제재 리스크가 있어 권하지 않음.
   - 네이버 검색광고(플레이스광고 쓸 경우): 공식 검색광고 API → n8n → 시트.
   - GA4: 네이티브 커넥터로 직접 연결(무료).
3. **대시보드**: Looker Studio 템플릿 1개 → 데이터 소스만 클라이언트 시트로 바꿔 복제. 페이지 1: 지표 6개 스코어카드(전월 대비), 페이지 2: 소재 TOP3/BOTTOM3, 페이지 3: 주간 추이.
4. **발송**: Looker Studio 예약 이메일(PDF)을 월 1일 사장님 메일로, 동시에 나는 PDF 링크 + §4.2 텍스트를 카톡으로. 텍스트의 "한 줄 결론·배운 것"은 LLM 초안 → 내가 5분 수정.
5. **유료 커넥터가 필요한 순간**: 클라이언트 10곳 이상, API 유지보수가 귀찮아질 때 — Windsor.ai / Porter / Supermetrics 류 파트너 커넥터(월 수만~수십만원대, raw/07 §5.1 Supermetrics $25~/월). 그 전까지는 시트 허브가 정답.

**주의**: 사장님에게 대시보드 링크를 상시 공개하면 "왜 어제 조회수 떨어졌어요?" 문의가 늘어난다. 대시보드는 **월 1회 PDF + 미팅용**, 상시 링크는 요청한 사장님에게만.

## 6. 이탈 방지 시스템

### 6.1 왜 나가는가
raw/01 §5-5: 이탈 이유는 가격이 아니라 **"소통 부족 + 결과 부재"**. 저가 고객일수록 1~3개월차 이탈. 대책으로 검증된 것: 3개월 최소 계약, "시스템 구축에 3개월 걸린다"는 사전 선언, 온보딩 퀵윈, 결제 자동 리마인더, 2년+ 유지 고객 만들기.

### 6.2 90일 설계

| 시점 | 장치 | 내용 |
|---|---|---|
| D0 | 기대치 선언 | 계약 시 "1개월: 세팅·소재 테스트, 2개월: 승자 찾기, 3개월: 숫자로 증명" 3단계를 문서로. "첫 달에 매출 오르면 운입니다"라고 먼저 말한다 |
| D3 | 퀵윈 3개 | §1.6 |
| D7·D14 | 주 2회 짧은 업데이트 | 온보딩 2주는 주 2회(raw/07 §5.3) |
| D30 | 첫 월간 리포트 + 10분 통화 | "시작값 대비" 첫 비교. 작더라도 오른 지표 1개는 반드시 있게 첫 달 소재를 설계(플레이스 조회는 사진·소개글만 바꿔도 오른다) |
| D45 | 사장님 숙제 확인 | 리뷰 카드 비치·클립 촬영 등 숙제 이행 여부. 미이행이면 "이게 안 되면 다음 달 숫자가 안 나온다"고 미리 말해 책임 소재 정리 |
| D60 | 승자 소재 광고 전환 제안 | 소액 업셀로 관여도 상승 |
| D90 | **리뷰 미팅 30분** | 아래 §6.3 |
| 이후 분기마다 | 리뷰 미팅 15분 + NPS | |

### 6.3 90일 리뷰 미팅 아젠다 (30분, 방문)
1. (5분) 3개월 숫자 1장: 시작값 → 현재. 좋은 것·안 된 것 각 2개.
2. (5분) 사장님 체감: "손님이 '인스타 보고 왔다'고 한 적 있나요?" — 정성 신호를 노션에 기록(후기 문장 소스).
3. (10분) 다음 분기 계획 + 필요한 협조 1개.
4. (5분) NPS 1문항 + 이유 1문항(§6.4).
5. (5분) 재계약·업셀 언급은 여기서 한 번만. 강요 없음.

### 6.4 NPS 질문 (카톡 또는 구글폼, 분기 1회)
```
사장님, 딱 두 개만 여쭐게요.
1) 아는 사장님에게 저를 추천할 가능성은 0~10점 중 몇 점인가요?
2) 그 점수를 준 가장 큰 이유 한 가지는요?
```
- 9~10: 후기·소개 요청(§8.4 문구). 7~8: 이유를 다음 달 계획에 반영. 0~6: 48시간 내 전화, 계약 조정 옵션 제시 — 조용히 나가게 두는 것보다 낫다.

### 6.5 이탈 신호와 대응

| 신호 | 판정 기준 | 대응 |
|---|---|---|
| 답장 지연 | 주간 리포트에 2주 연속 무반응 | 리포트를 30초 음성 메시지 또는 전화로 전환. "바쁘실 텐데 숫자만 하나 말씀드리면…" 사람 목소리로 관계 복구 |
| 승인 지연 | 자동 승인 2주 연속 | 콘텐츠에 불만인지, 그냥 바쁜지 전화로 확인. 불만이면 톤 가이드 재정의 미팅 15분 |
| 결제 지연 | D+3 리마인더에도 무응답 | §5.5 단계 적용. 자금 문제면 다운그레이드 플랜 제안(해지보다 낫다) |
| 성과 질문 급증 | "이거 효과 있는 거 맞아요?" | 리포트 밖 지표(사장님 체감 문의 수)를 같이 세는 방법 합의, 시작값 표 다시 보여주기 |
| 경쟁 대행사 언급 | "다른 데는 ○○ 해준다던데" | 방어하지 말고 "그 항목 저도 넣을 수 있는지 다음 주까지 답드릴게요". 블랙햇(리뷰 작업 등)이면 §7.4 답변 |
| 담당자 교체 | 직원이 승인 담당으로 바뀜 | 15분 온보딩 통화 재실시, 노션 링크 재발송 |

## 7. 사고 대응 매뉴얼

각 항목: **즉시 조치 → 사장님 통보 문장 → 재발 방지**. 통보는 발견 후 2시간 내, 내가 먼저. 사장님이 먼저 알게 하면 신뢰가 깨진다.

### 7.1 메타 광고 거부 / 광고계정 제한
- **즉시 조치**: ① 광고 관리자에서 거부 사유 확인(개인 속성 언급·비포애프터·건강 효능 단정·과도한 텍스트·랜딩 불일치가 로컬 업종 단골 사유, 일반 지식) ② 사유가 명확하면 소재 수정 후 재제출, 불명확하면 "검토 요청"(계정 품질 페이지에서 이의 제기) ③ 계정 제한이면 사장님 BM 관리자(사장님)가 신원 확인·검토 요청을 해야 하는 경우가 있으니 화면 공유로 같이 진행 ④ 그동안 오가닉 발행은 정상 유지, 예산은 플레이스광고 등 대체 채널로 임시 이동 검토.
- **통보**: "사장님, 오늘 광고 1건이 메타 정책(○○ 사유)으로 거부됐습니다. 계정 자체는 정상이고, 문구 수정해서 오늘 재제출했습니다. 보통 24시간 내 결과가 나오고, 그동안 다른 광고는 정상 노출 중입니다."
- **재발 방지**: 업종별 금지 표현을 파이프라인 필터에 추가, 병원·뷰티는 소재 승인 전 "메타 정책 체크" 항목 별도, 광고계정을 사장님 BM 소유로 두어 제재가 다른 클라이언트로 번지지 않게(이미 §1.4 구조).

### 7.2 네이버 블로그 저품질 / 플레이스 노출 급락
- **즉시 조치**: ① 급락 범위 확인(특정 키워드만인지, 전체 검색 노출인지, 블로그 전체인지) ② 최근 2주 변경 이력 대조(정보 대량 수정·카테고리 변경·리뷰 급증·동일 문구 반복 발행·외부 링크·다운로드 이미지) ③ 의심 원인 콘텐츠는 비공개 ④ 네이버 고객센터 문의 접수(플레이스는 스마트플레이스 센터 1:1) ⑤ 대량 신규 발행 중단, 주 2회 정상 발행 유지.
- **통보**: "사장님, 이번 주 플레이스 '○○동 맛집' 노출이 3위 → 15위권으로 떨어졌습니다. 지난주 리뷰가 평소의 4배로 몰린 게 원인으로 보입니다(리뷰 이벤트 영향). 이벤트는 오늘 잠시 멈추고, 네이버에 문의 넣었습니다. 보통 2~4주 지켜봐야 하고, 그동안 인스타·광고는 정상입니다."
- **재발 방지**: 리뷰는 "몰아서"가 아니라 주간 꾸준히(raw/07 §4.2 — 특정 시기 집중 리뷰·대가성 리뷰는 블라인드·플레이스 패널티 위험), 블로그는 주제 집중·원본 이미지·1,500자+·복붙 금지 규칙을 파이프라인에 고정, 플레이스 기본 정보는 월 1회만 일괄 수정.

### 7.3 악성 리뷰 폭탄
- **즉시 조치**: ① 리뷰 캡처·시간·계정 목록 보존 ② 명백한 허위·비방·경쟁사 의심은 플랫폼 신고(플레이스 리뷰 신고, 인스타 댓글 신고) ③ 사실 기반 불만은 **24시간 내 정중한 답글 1회**(반박 금지, 사과+개선+오프라인 연락 유도) ④ 절대 하지 말 것: 지인 동원 별점 방어, 삭제 업체 이용(둘 다 어뷰징·표시광고법 리스크) ⑤ 연속 폭탄이면 그 주 콘텐츠 발행 톤을 낮추고 광고 일시 정지 검토(광고가 악플을 증폭).
- **통보**: "사장님, 오늘 오후 2시간 사이에 1점 리뷰 7개가 한꺼번에 달렸습니다. 계정 패턴상 한 그룹으로 보여 네이버에 신고했고 캡처는 보관 중입니다. 답글은 제가 한 건씩 정중하게 달고 있습니다. 혹시 최근 매장에서 있었던 일이나 짐작 가는 분이 있으면 알려주세요. 사장님이 직접 답글 다시는 건 잠시 참아주세요."
- **재발 방지**: 리뷰 답글 표준 문안 3종(불만·오해·허위) 노션 보관, 평소 리뷰 흐름을 꾸준히 만들어 한두 개 악플의 비중을 낮추기, 리뷰 모니터링 알림(n8n으로 새 리뷰 감지 → 카톡 알림).

### 7.4 사장님이 "작업" 요구할 때 (리뷰 작업·트래픽 작업·상위 노출 보장·팔로워 구매)
- **즉시 조치**: 거절하되 대안을 같이 낸다. 계약서 "블랙햇 금지" 조항을 근거로.
- **답변 문장**: "사장님, 그건 제가 안 합니다. 이유는 두 가지예요. 하나는 네이버가 리뷰 작업을 잡으면 리뷰 몇 개 내려가는 게 아니라 플레이스가 검색에서 통째로 밀리고, 회복에 몇 달 걸립니다. 다른 하나는 대가 준 리뷰를 표시 안 하면 공정위 표시광고법 위반이라 과태료·과징금이 사장님께 갑니다. 대신 합법적으로 같은 효과 내는 방법이 있어요 — 영수증 리뷰 안내 카드(대가 명시), 방문 후 카톡 리뷰 요청, 사진 리뷰 이벤트. 이건 제가 이번 주에 세팅해 드릴게요. 그래도 작업 업체 쓰시겠다면 말리진 못하지만, 그 기간 성과 하락은 제 책임 범위 밖이라는 것만 문서로 남기겠습니다."
- **재발 방지**: 계약서에 "회사는 리뷰 조작·트래픽 조작·순위 보장 서비스를 제공하지 않으며, 클라이언트가 제3자를 통해 이를 수행할 경우 그로 인한 노출 하락·제재는 회사의 책임 범위에서 제외된다" 조항. 영업 단계에서 "우리는 작업 안 합니다"를 차별점으로 먼저 말한다.

### 7.5 콘텐츠 저작권 클레임 (음원·사진·폰트·타인 영상)
- **즉시 조치**: ① 해당 콘텐츠 즉시 비공개(플랫폼 뮤트·삭제 요청 포함) ② 소스 추적(파이프라인 로그: 어느 음원·이미지·폰트를 썼는지) ③ 권리자 연락이 왔으면 24시간 내 정중 회신(삭제 완료 통지, 사용 경위, 합의 의사) ④ 내 과실(라이선스 없는 소스)이면 비용은 내가 부담 — 계약서 소재 저작권 조항대로.
- **통보**: "사장님, 8/20 릴스에 쓴 배경 음원에 대해 권리자 측 이의가 들어와 바로 내렸습니다. 소스 확인 결과 제 쪽 실수라 처리·비용은 제가 책임집니다. 사장님 계정에는 경고 1회가 남을 수 있는데, 추가 조치 없도록 제가 대응 중입니다."
- **재발 방지**: 릴스 음원은 인스타 앱 라이브러리(비즈니스 계정용)만, 파이프라인은 라이선스 확보 음원·상업용 폰트(예: 눈누 상업용 무료 폰트)·클라이언트 원본 사진만 쓰는 화이트리스트, 소스 로그를 콘텐츠 카드에 자동 첨부.

### 7.6 표시광고법 민원 (뒷광고·과장·대가 미표시)
- **즉시 조치**: ① 문제 콘텐츠 캡처 후 수정 또는 비공개 ② 대가성 콘텐츠 전수 점검 — "광고" 표기가 첫 줄/첫 화면에 있는지(더보기·해시태그 더미 속 표기는 불충분, 심사지침 취지) ③ 공정위·지자체 민원 접수 통지를 받았으면 사장님과 함께 답변서 작성(사실 관계·수정 조치·재발 방지), 필요 시 전문가(법무) 연결 ④ 병원·의료기기·건강 효능은 의료광고법·식품표시법 병행 확인.
- **통보**: "사장님, 7월 블로그 리뷰 이벤트 글에 '대가 제공' 문구가 본문 첫 줄이 아니라 끝에 있어서 표시 위치 지적이 들어왔습니다. 오늘 전 글 첫 줄로 수정했고, 릴스도 전수 확인했습니다. 과태료 여부는 민원 처리 결과에 따르는데, 자진 시정 사실을 답변에 넣겠습니다."
- **재발 방지**: §2.3 체크리스트 1번을 자동 검사(캡션 첫 20자 내 "광고" 문자열), 리뷰 이벤트 안내물 표준 문안("본 리뷰는 ○○을 제공받아 작성"), 6월 개정 심사지침 내용을 분기 1회 재확인.

### 7.7 공통 — 사고 로그
노션 "사고 로그" DB: 날짜·클라이언트·유형·원인·조치·사장님 통보 시각·재발 방지 반영 여부. 월간 리포트 "배운 것"에 필요한 만큼만 공유(숨기지 않되, 공포 조성도 하지 않는다).

## 8. 오프보딩 SOP (해지 통보 ~ 종료일 + 30일)

### 8.1 원칙
- 떠나는 사장님도 추천원이다(raw/01 §4-1: "다리 태우지 말 것"). 마지막이 가장 좋은 서비스여야 한다.
- 자산은 처음부터 사장님 소유였으므로 "인계"가 아니라 "내 접근 제거 + 원본 전달"이다.

### 8.2 타임라인

| 시점 | 할 일 |
|---|---|
| 해지 접수 당일 | 카톡 회신 "알겠습니다, 마지막 달도 똑같이 하겠습니다". 이유를 한 문장만 묻는다(NPS 0~6 대응과 동일). 계약 §해지 통보 30일 확인, 종료일·마지막 결제 확정 |
| 종료 D-14 | 예약 발행 목록 정리(종료일 이후 예약 게시물은 사장님 확인 후 유지/삭제), 광고는 종료일에 일시정지 예약(사장님 카드이므로 켜둔 채 떠나지 않는다) |
| 종료 D-7 | 자산 인계 패키지 준비(§8.3), 최종 리포트 초안 |

| 종료 D+90 | 안부 1통 + 재계약 제안(§8.6) |

### 8.3 자산 인계 패키지 (구글 드라이브 폴더 "99_인계_YYMM")
- `01_원본`: 사장님이 보낸 클립·사진 전체(원본 화질)
- `02_완성본`: 발행한 릴스 mp4 전체, 블로그 본문 md/docx + 사용 이미지, 플레이스 소개글·메뉴 텍스트, 캔바 템플릿 공유 링크(복제 가능)
- `03_데이터`: 지표 시트 사본, 광고 소재별 성과 CSV, 소재 네이밍·UTM 규칙, 승자 소재 목록
- `04_가이드`: 톤 가이드·금지 표현·촬영 가이드 1장·발행 요일/시간 추천 — "다음 담당자가 이대로 하면 됩니다"
- `05_계정`: 권한 표(무엇을 누구에게 줬고, 어떻게 해제하는지). 비밀번호는 애초에 없다. 블로그 기기 등록은 해제 방법 안내.
- 전달 후 "이 폴더의 소유권을 사장님 계정으로 이전했습니다" — 드라이브 소유권 이전 기능 사용.

### 8.4 권한 회수 순서 (사장님이 하는 것 + 내가 확인)
1. 메타: 사장님 BM → 비즈니스 설정 → 파트너 → 내 비즈니스 제거(광고계정·페이지·인스타·픽셀 접근 동시 소멸). 시스템 사용자 토큰은 내가 먼저 폐기.
2. 네이버 검색광고: 사장님 계정 → 권한설정 → 권한 철회. (내 쪽 "권한 받기" 목록에서 사라진 것 캡처)
3. 스마트플레이스: 업체 관리 → 관리자 → 내 ID 삭제.
4. 네이버 블로그: 내 기기 로그아웃 + 사장님 계정 "로그인 기기 관리"에서 내 기기 삭제, 2차 인증 재설정 권장.
5. GA4/아임웹/카카오 채널: 사용자 관리에서 내 이메일 제거.
6. 카톡 채널 1:1 채팅은 유지(추천·안부 채널). 노션 페이지는 30일 후 아카이브.
7. n8n 워크플로 비활성화, 시트 API 연결 해제, 내 로컬의 클라이언트 토큰·자료 삭제.
- 순서 이유: 토큰·자동화를 먼저 끊고(내 쪽), 그다음 사장님이 파트너를 제거해야 "끊긴 자동화가 오류 알림을 사장님에게 보내는" 상황이 없다.

### 8.5 최종 리포트 + 후기 요청
- 최종 리포트 = §4.2 형식 + "계약 전체 기간 시작값 → 종료값" 표 1개 + "다음 담당자에게 권하는 3가지".
- 후기 요청 문장: "사장님, 그동안 감사했습니다. 한 가지만 부탁드리면, 저와 일하며 좋았던 점 두 줄만 카톡으로 남겨주실 수 있을까요? 제 소개 자료에 상호와 함께 쓰겠습니다(원치 않으시면 상호는 뺍니다). 그리고 혹시 주변에 저 같은 사람 필요한 사장님 계시면 편하게 소개해 주세요."
- 후기는 캡처 + 사용 동의 문구를 노션 "케이스" DB에 저장(표시광고법: 후기는 실제 고객의 실제 경험만, 대가 제공 없이).

### 8.6 재계약 제안 (D+90)
"사장님, 잘 지내시죠? 종료 후 3개월이 지나 안부 겸 연락드립니다. 요즘 플레이스 보니 사진이 그대로여서, 혹시 필요하시면 릴스 없이 플레이스+블로그만 하는 경량 플랜(월 25만원)도 새로 만들었습니다. 부담 없이 보시고, 아니면 그냥 안부로 받아주세요."
- 복귀 고객은 온보딩 비용이 0에 가깝다. 경량 플랜은 이런 용도로 존재한다.

전제: 본업 평일 9~18시, 대행 작업은 평일 아침 1시간 + 저녁 1.5시간 + 주말 반나절. 총 **주 약 17~19시간**(클라이언트당 1.7~1.9시간).

| 시간 | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
|---|---|---|---|---|---|---|---|
| 07:00~08:00 | 10곳 광고 지표 스캔(자동 시트) + 이상 징후 체크 | 릴스 발행 5곳(예약) + 리뷰 답글 | 릴스 발행 5곳 + 블로그 2편 | 릴스 발행 + 광고 킬룰 적용 | 주간 3줄 리포트 10곳(LLM 초안 → 수정 → 발송) | — | — |

- **월요일 저녁 검수가 전체의 병목**이다. 파이프라인 검수 통과율이 80%를 넘도록 프롬프트 규칙을 계속 고친다 — 검수 시간이 곧 마진이다.
- 월초 첫 주말은 월간 리포트 2.5시간이 추가된다(Looker Studio PDF 자동 + 문장 작성). 이 주는 방문 촬영을 잡지 않는다.
- 신규 온보딩 1곳당 6~8시간이 추가되므로 **월 1~2곳만 신규 수주**. 동시 온보딩 3곳이면 기존 10곳 품질이 떨어진다.
- 90일 리뷰 미팅(30분+이동)은 분기당 10건 → 주말에 2~3건씩 분산.
- 본업 회의·야근이 겹치는 주를 위한 안전장치: 릴스는 항상 **1주 앞서** 렌더·승인·예약 게시. 최악의 주에도 발행은 끊기지 않게.
