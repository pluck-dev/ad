# A. 스마트플레이스(지도) 실무

## A1. 사장님 계정에 대행사 권한 추가하기

### A1-1. 권한 구조부터 이해하기 [공식]

스마트플레이스에는 두 층의 권한이 있다.

| 권한 | 누가 갖나 | 할 수 있는 것 | 못 하는 것 |
|---|---|---|---|
| **주인(관리자, 관리권한)** | 사업자 본인 네이버 ID **1개** | 업체정보 수정, 통계 열람, 리뷰 답글, 쿠폰·소식·스마트콜, 운영자 추가/삭제, 주인 권한 위임, 예약/주문 설정 전부 | — |
| **운영자** | 주인이 초대한 네이버 ID (예약 서비스별 **최대 60명**) | 예약/주문 관리, (톡톡 가입 시) 톡톡 상담 | 서비스 삭제, 플레이스 노출 설정, Npay 가입, 톡톡 연동, 다른 운영자 추가/삭제, **권한관리 메뉴 자체가 보이지 않음** |

- 출처: 「예약/주문 관리자가 여러 명일 경우(운영자 추가)」 https://help.naver.com/service/30026/contents/20715
- 주의: 도움말 원문은 "운영자 권한은 **사업자님의 내부 직원에게만** 부여할 수 있습니다. 위반 시 개인정보보호법상 동의 없는 제3자 제공(5년 이하 징역 또는 5천만원 이하 벌금)에 해당할 수 있다"고 명시한다. 운영자는 예약 고객의 휴대폰 번호 등 개인정보를 열람할 수 있기 때문이다.
- **대행사 실무 해석 [실무자+일반]**: 운영자 권한을 받으려면 사장님과 (1) 개인정보 처리 위탁 계약(개인정보보호법 제26조) (2) 업무 위탁 계약서를 반드시 문서로 남긴다. "내부 직원"이 아닌 외부 대행사가 예약 고객 개인정보를 다루는 근거를 계약으로 만들어 두는 것이다. 이 계약이 없으면 권한을 받지 않는 게 안전하다.
- **통계·업체정보 수정은 주인 권한 전용** [공식 20520, 20545, 20504]: 통계 탭, 리뷰 키워드 설정, 평균 별점 노출 설정 등은 "주인 권한 아이디로 로그인"해야 한다. 즉 운영자 권한만으로는 플레이스 최적화 작업 대부분을 할 수 없다.

### A1-2. 그래서 대행사는 실무에서 어떻게 하나 [실무자·일반]

현실적인 3가지 방식. 위험도 순으로 나열.

1. **사장님이 직접 수정, 대행사는 가이드 제공** (가장 안전): 대행사가 수정할 내용을 문서(소개글·키워드·메뉴 텍스트·사진 파일)로 만들어 보내고, 사장님(또는 직원)이 주인 ID로 입력. 월 1회 화면 공유로 함께 점검.
2. **운영자 권한 + 계약**: 예약·주문·톡톡 응대와 리뷰 모니터링만 대행. 정보 수정은 1번 방식 병행.
3. **주인 ID 공유** (권장하지 않음): 보안·책임 문제. 부득이하면 사장님 명의 업무용 네이버 ID(개인 ID와 분리)를 새로 만들어 주인 권한을 위임하고, 계약 종료 시 다시 사장님 개인 ID로 위임하는 방식으로 제한. 네이버는 1인당 3개 ID까지 허용(실무자 블로그 인용).

### A1-3. 운영자 추가 절차 (화면 단위) [공식 20715]

1. 스마트플레이스에 **주인(관리자) ID**로 로그인 (https://new.smartplace.naver.com)
2. 오른쪽 위 초록색 닉네임/ID 또는 메뉴(≡) 클릭
3. **권한관리** 클릭
4. **예약·주문 운영자 관리** → **운영자 추가**(또는 "운영자 N명") 클릭
5. 추가할 네이버 ID 입력 → **동의 및 추가**
   - "미가입 ID" 안내가 뜨면: 그 ID로 로그인 → 스마트플레이스 > 예약/주문 접속 → 약관 동의만 하면 가입됨
6. 초대받은 ID에 네이버 알림 발송
7. 초대받은 사람이 알림에서 **동의하기**를 눌러야 완료 (안 누르면 추가 안 됨)
   - 알림이 안 오면: 네이버 홈 > 알림(종) > 톱니 > 알림설정 > 서비스별 설정 > 네이버예약 > 푸시 알림 ON
- 삭제: 권한관리 > 운영자 N명 > ID 오른쪽 X > 삭제. **삭제된 운영자 ID는 복구 불가**, 직원 퇴사·계약 종료 시 즉시 삭제.
- 1개 네이버 ID가 받을 수 있는 운영자 권한 수는 제한 없음(여러 업체 운영자 가능) → 대행사 ID 1개로 여러 클라이언트 운영자 가능.

### A1-4. 주인 권한 위임 (사장님 ↔ 직원/명의 변경 시) [공식 20522, 20713]

- 플레이스만 있는 업체: 스마트플레이스 > 내 업체 > 업체명 > 더보기(⋯) > **주인 권한 위임** > 위임받을 네이버 ID·이름 입력. **7일 이내** 상대방이 등록 내역에서 수락해야 하며, 미수락 시 자동 취소. 완료 시 회원정보 이메일로 안내 메일.
- 예약/주문 사용 업체: **권한관리에 등록된 운영자에게만** 위임 가능. 경로: 메뉴(≡) > 권한관리 > 주인 권한 위임 > 다음 > 운영자 선택 > 동의하기.
- [실무자] 위임 과정에서 **스마트콜이 해지될 수 있다**는 안내가 뜬다. 위임 후 반드시 스마트콜 재설정을 확인(전화 유입이 끊기는 사고 방지). 출처: blog.naver.com/cleanbird00/224314726915
- 이전 관리자와 연락이 안 될 때: 「플레이스 주인 변경/신청」(https://help.naver.com/service/30026/contents/20521) — 업체 찾기 > 주인변경 > ARS(대표번호로 즉시) 또는 서류(사업자등록증, 영업일 최대 5일). 대표자가 아니면 사업자등록증+재직증명서.
- 예약 권한과 플레이스 권한이 불일치할 때: 「예약X스마트플레이스 권한 통합 방법」 https://help.naver.com/service/11712/contents/9445

### A1-5. 온보딩 체크리스트 (권한 편)

- [ ] 사장님 네이버 ID 실명 인증 여부 확인 (스마트플레이스·광고주센터 모두 실명 ID 필요)
- [ ] 현재 주인 ID가 누구인지 확인 (이전 대행사·퇴사 직원 ID면 주인 변경/위임 먼저)

## A4. 플레이스광고 세팅 (검색광고 상품)

### A4-1. 상품 이해 [공식]

- 플레이스광고 = 스마트플레이스 등록 업체 정보를 바탕으로 생성되는 네이티브 광고. **키워드를 직접 등록하지 않고** 업체 연관 키워드에 자동 매칭. CPC(클릭당 과금), **최저 50원~최대 5,000원(VAT 별도), 10원 단위**. 미설정 시 50원으로 참여. 노출 지면: 통합검색·플레이스 서비스·지도 웹/앱·파트너 매체. 지역·매체·요일/시간 전략 설정 가능. 음식점·병원·학원 등 다양한 업종 가능. (ads.naver.com/help/faq/1044, /faq/1353)
- **일 예산 상한: 광고그룹당 10만원, 캠페인당 10만원**. 입찰은 광고그룹 단위. 노출 원치 않는 검색어는 광고그룹 **제외검색어**로 관리. 입찰지원도구 제공. (faq/1353)
- 검색 결과에서 "광고" 표시가 붙은 플레이스가 이 상품. (도움말 20518)
- 형제 상품 **지역소상공인광고**: 네이버 뉴스·블로그·우리동네 판 등 콘텐츠 지면 배너. **유효 노출당 0.5원 고정, 하루 최대 3만회**. 스마트플레이스 > 마케팅 > 지역소상공인광고에서 소재(업체명·문구·이미지·유효기간) 설정 후 광고주센터에서 플레이스 연결. 광고 차단 기능 없음. (saedu.naver.com 검색광고 소개, 도움말 20517·20519)
- 스마트플레이스 신규 등록 완료 페이지 하단에 검색광고 쿠폰(실무자: 5만원)이 지급됨 → 첫 광고 테스트에 사용. 광고주센터도 "첫 광고 50만원 지원" 프로그램 안내 중(조건 확인 필요).

### A4-2. 세팅 단계

1. 광고주센터(ads.naver.com) 로그인 → 광고 계정 선택 (B1 절차로 권한 받은 상태)
2. 구성요소 관리 > **비즈채널** > 채널 추가 > **플레이스** 유형 > 스마트플레이스 업체 연결 (주인 ID와 광고주 ID가 다르면 연동 확인 절차) → 검수 통과 대기
3. 광고 관리 > 캠페인 만들기 > 유형 **플레이스** > 캠페인 이름·일 예산(최대 10만원)
4. 광고그룹 만들기 > 플레이스 비즈채널 선택 > 기본 입찰가(초기 300~800원 [실무자 권장], 긴급출동 업종은 상한 5,000원 경쟁) > 고급옵션: 지역(매장 반경 시·구 단위), 매체(PC/모바일), 요일/시간(영업시간 중심), 입찰 가중치
5. 소재: 업체 정보 기반 자동 생성. 대표 사진·소개 문구가 광고 소재가 되므로 **A2 최적화가 곧 광고 소재 품질**
6. 제외검색어 등록 (예: "채용", "알바", 타 지역명, 무관 업종)
7. 검수 승인 후 노출 → 1주 후 보고서 확인

### A4-3. 입찰·예산 판단 기준 [실무자 종합: dh_planet, admanseok, sohotip]

- 처음엔 낮게(300~500원) 시작해 노출·클릭 확인, 순위가 안 나오면 100~200원씩 상향. "입찰가를 올리면 노출은 누구나 쉽지만 최적 세팅은 아니다."
- 판단 지표: 클릭당 비용 × 클릭 = 실지출. 전화·예약·길찾기 전환(플레이스 통계 + 스마트콜 통계로 확인)당 비용이 사장님이 감당할 객단가 대비 남는지가 기준.
- 예산 기준(1인 대행 실무 초기값): 음식점·카페 일 1~2만원, 뷰티·학원 일 2~3만원, 병원·긴급출동 일 3~5만원(상한 10만원). 2주 데이터 뒤 조정.
- 긴급출동성 업종(누수·열쇠·보일러·에어컨·청소·해충·견인)은 입찰가 5,000원 상한에 몰려 있어 순위 경쟁이 극심 → 파워링크 병행.
- 광고 켜기 전 플레이스 정보·사진·리뷰 답글부터 정리. "광고는 데려오는 역할, 플레이스 관리는 선택하게 만드는 역할"(delia_bean).

### A6-1. 스마트플레이스 통계 메뉴 구성 [공식 20520·20524·20527·20530·20532, 예약 통계 20754~20759]

# B. 네이버 검색광고 실무

## B1. 광고주 계정 생성 → 비즈채널 → 대행사 권한

### B1-1. 2026년 시스템 변화 먼저 알기 [공식]

- 2026년 3월 **네이버 광고주센터(ads.naver.com)** 오픈으로 검색광고(searchad)와 GFA가 통합. 구조: **회원(네이버 ID) → 관리계정 → 광고계정 → 캠페인 → 광고그룹 → 키워드/소재**. 하나의 광고계정에 최대 5개 관리계정 연동, 관리계정 상위로 최대 5단계. (운영정책 제2조)
- 기존 "프리미엄 로그분석 > 웹로그분석 조회" 바로가기는 종료, 네이버 애널리틱스는 별도 사이트 등록·스크립트 설치 필요. (공지 29543)
- 2026-07-21부터 **AI 광고**(AI 브리핑 지면, ADVoost 검색광고 대상, 확장검색 예산 사용, 입찰가 설정 불가, 소재는 AI가 작성)가 출시. 확장검색 사용 그룹은 기본 켜짐이므로 소액 계정은 확인 후 끌지 결정. (공지 31888)
- 이 매뉴얼의 화면 경로는 광고주센터 기준이며, 인터넷에 있는 "searchad.naver.com > 도구 > 권한설정(광고관리/성과조회/로그분석/세금계산서 8종 조합, 계정당 3명)" 설명은 **구 시스템** 기준이다(raw/07 §6.4 표도 구 기준). 새 시스템에서는 아래 3종 권한으로 바뀌었다.

### B1-2. 광고주(사장님) 계정 생성 [공식 운영정책 제1·2조]

1. 사장님 본인의 **실명 인증된 19세 이상 네이버 ID**로 ads.naver.com 회원가입 (대행사 ID로 만들지 않는다 — "적법한 위탁 권한 없이 타인의 사업을 광고하기 위해 계정을 생성·운영"하면 이용 제한 사유)
2. 광고 계정 생성: 사업자등록 완료 → **사업자 광고주**(사업자등록번호·세금계산서 정보 입력). 미등록이면 개인 광고주(세금계산서는 영수증빙용). 사업자→개인 전환 불가.

### B1-3. 비즈채널 등록·검수 [공식 saedu, 실무자 grow_jh·saeum__m]

- 비즈채널 = "광고가 도착할 목적지"(웹사이트·전화번호·통화추적번호·위치정보·네이버 예약·플레이스·스마트스토어·톡톡 등). **비즈채널 없이는 캠페인 생성 자체가 불가.** 계정당 총 1,000개, 통화추적번호 50개, 톡톡 5개.

  - 웹사이트: 이름·URL(http/https 선택)·회원제 사이트면 테스트 계정
  - 전화번호: 일반 전화번호 vs 통화추적번호 선택
  - 위치정보: 사업자명 + 주소 찾기(지번·도로명)
  - 플레이스: 스마트플레이스 업체 연결 (플레이스광고·확장소재 "플레이스정보"용)
  - 네이버 예약: 예약 연결하기
  - **사이트 이름**은 AI 광고 노출 시 그대로 쓰이므로 가독성 있게(공지 31888)
- 검수: 업종에 따라 사업자등록증·인허가 서류(병원=의료기관 개설신고증, 학원=학원설립운영등록증 등) 요구. 광고 시작일이 정해져 있으면 검수 기간(보통 영업일 1~3일, 서류 업종은 더)을 일정에 반영. 검수 상태·프리미엄 로그분석 연동 여부는 비즈채널 목록에서 확인.
- **주의**: 웹사이트 채널을 삭제하면 하위 광고그룹·키워드·소재·확장소재 전체 삭제 + 품질지수 소멸, 복구 불가. 채널은 "수정"으로 처리.

## B2. 파워링크 캠페인 구조·키워드·입찰·소재

### B2-1. 구조 [공식 saedu + 실무자 saeum__m]

- 광고계정 → **캠페인**(유형: 파워링크/쇼핑검색/파워컨텐츠/브랜드검색/신제품검색/플레이스/지역소상공인) → **광고그룹**(비즈채널·기본 입찰가·매체·지역·요일시간·예산) → **키워드 + 소재 + 확장소재**
- 통합검색 노출 순서: 브랜드검색 > 네이버 직접 제공 콘텐츠(인물·환율 등) > 파워링크 > 비즈사이트. 반응 낮은 키워드는 파워링크만 노출되거나 위치가 바뀔 수 있음.
- 로컬 클라이언트 표준 구조 [실무자]: 캠페인 1개(파워링크) → 광고그룹을 **키워드 주제별 + PC/모바일 분리**로 4~8개. 예: [모바일] 강남 필라테스_지역, [모바일] 필라테스 1:1_서비스, [모바일] 필라테스 가격_구매의도, [PC] 동일 3개. 소액이면 모바일만.
- 예산은 캠페인·광고그룹 양쪽에 설정 가능. 모바일 입찰 가중치 110% 정도 상향 관행.
- 처음엔 **파워링크 단일 유형**으로 데이터를 쌓고, 병원·학원·시술처럼 설명이 필요한 업종은 파워컨텐츠, 오프라인 매장은 플레이스광고를 나중에 추가.

### B2-2. 키워드 20~50개 뽑는 법

1. 키워드 도구(A3-3)에서 씨앗 키워드 5개(업종·지역·대표 메뉴/시술·상황·브랜드명) 입력 → 연관 키워드 전체 다운로드
2. 분류: **구매/지역형**(강남 필라테스 가격, 역삼 치과 임플란트 비용) / **정보형**(필라테스 효과) / **브랜드형**(상호명) / **무관**(채용·자격증·중고·타지역)
3. 우선순위: 구매·지역형 롱테일(3~4단어, 월 검색 100~2,000) 20~30개 + 지역+업종 핵심 5~10개 + 브랜드명 2~3개 = 30~45개. 대표 단어("필라테스")는 초기 제외.
4. 광고그룹 > 키워드 탭 > 새 키워드 > 직접 입력(한 줄 1개) 또는 연관 키워드 추천. 한 번에 100개, 그룹당 최대 1,000개. [실무자 ygray4250]
5. 매칭: **일치검색**(등록 키워드와 정확히 일치)과 **확장검색**(유사·관련 검색어 자동 확장). 핵심·브랜드·고전환 키워드는 일치, 신규 발굴용 그룹만 확장 + 확장검색 예산 상한 30~40% + 주 1회 검색어 리포트로 제외키워드 등록. 확장 미관리 캠페인은 관리 캠페인보다 ROAS 약 30% 낮았다는 실무자 데이터(beaulead). [실무자]
6. 무효 클릭: 광고주센터 > 도구 > 무효클릭 관리에서 IP 제외·조사 요청 가능(raw/04 §2 부정클릭 판례 참고).

### B2-3. 입찰 전략 (순위 vs 예산) [실무자 종합: uni_on_co, saeum__m, inobean]

- 노출순위 = 입찰가 × 품질지수(7단계 막대, 신규 4단계 시작, 키워드-소재 연관성·CTR·랜딩 적합성 반영). 실제 과금은 바로 아래 순위 입찰가 기준 → 입찰가는 상한선, 보고서의 **평균 클릭비용**을 봐라.
- 파워링크 입찰가 범위: 최소 70원~최대 10만원 [실무자 saeum__m]. 시스템의 "순위별 예상 입찰가" 조회 후 상한 설정.
- 초기 2주: 세부 키워드를 낮은 입찰가로 시작 → 클릭·문의 데이터 확보 → 전환 나온 키워드만 순위 상향, 클릭만 먹는 키워드는 하향/OFF.
- **1위가 항상 남는 자리가 아니다**: 1~2위는 탐색 단계 클릭이 섞이고 CPC가 급등. 확장소재를 채우면 3~5위에서도 충분한 클릭. 예외: 상호명 키워드·계약 직전 키워드는 상단 유지.
- 목표는 순위가 아니라 **키워드별 목표 CPA**(문의 1건당 허용 비용) 안에서의 순위. 자동입찰은 데이터 쌓인 뒤, 핵심 키워드는 수동 유지.
- 입찰가 상한 + **일 예산 상한**을 세트로. 시간대별 보고서로 전환 몰리는 시간(병원=진료시간, 음식점=식사 1~2시간 전)에 입찰 가중치, 심야 OFF.

### B2-4. 확장소재 [실무자 ygray4250 + 공식 도움말 인용]

- 종류: 전화번호, 네이버예약, 계산, 추가제목(최대 15개·15자), 추가설명(최대 4개·45자), 홍보문구(2개), 서브링크(2개), 이미지형 서브링크, 파워링크 이미지(2개), 플레이스 정보(1개, 스마트플레이스 기반), 홍보영상·블로그리뷰(최대 5개), 쇼핑정보(1개), 웹사이트정보. 캠페인 단위는 전화번호·네이버예약만, 나머지는 광고그룹 단위.
- 경로: 광고 관리 > 캠페인/광고그룹 > 확장 소재 탭 > +새 확장소재 > 유형·입력 > 고급옵션(요일/시간/기간). 심사 통과 + 성과 조건 충족 시 노출(등록해도 항상 보이진 않음).
- 로컬 필수 조합: 전화번호(전화 전환 업종은 랜딩 없이 가장 짧은 전환 경로) + 플레이스 정보 + 네이버예약 + 서브링크(가격/오시는길/후기/예약) + 홍보문구(이벤트). 병원·성인·주류 등 일부 업종은 홍보영상·블로그리뷰·쇼핑정보 불가.

### B2-5. 지역·시간·기기 타게팅, 일 예산

- 광고그룹 고급옵션: **매체**(PC/모바일, 통합검색/콘텐츠 지면), **지역**(시·군·구 단위 노출 지역 선택 — 로컬 매장은 매장 반경 구 단위 + 인접 구), **요일/시간**(1시간 단위 ON/OFF·입찰 가중치), **PC/모바일 입찰 가중치**. [공식 상품 설명 + 실무자]
- 일 예산: 캠페인·광고그룹에 설정. 예산 소진 시 광고 중단(시간대 편중 방지를 위해 균등 노출 옵션 확인). 초기값 [실무자]: 소상공인 일 1~3만원(월 30~90만원)에서 시작, 전환당 비용이 목표 안이면 20~30%씩 증액.

### B2-6. 소재 작성 규칙·심사 [실무자 ygray4250·ampm + 공식 광고 등록 기준]

- 반응형 소재: 제목 최소 3개~최대 15개(각 **15자 이내**), 설명 최소 2개~최대 4개(각 **20~45자**). 단일형: 제목 1개(15자)·설명 1개(20~45자). 성과 좋은 조합이 자동 우선 노출 → 소재 2개 이상 등록 = 계정 내 A/B 테스트.
- **키워드 삽입** `{키워드:대체키워드}`: 검색어가 제목에 볼드로 삽입, 글자수 초과 시 대체키워드 노출 → 연관성·CTR 상승.
- 심사 기준: 특수문자 과다 금지, "최고·최초·1위·No.1"은 증빙 필요(광고 등록 기준), 띄어쓰기·오탈자, 랜딩페이지와 불일치 금지, 업종별 법령(의료광고 사전심의, 학원법 표시, 화장품법 효능 표현, 식품 표시). 위반 시 "등록 불가" 또는 "소명 필요".
- 카피 공식: [지역+업종 키워드] + 구체 사실(운영 연차·시술 건수·대응 범위) + 혜택(첫 방문 할인·당일 예약) + CTA(전화·예약). 성별·연령별 소구 분리(ampm).
- 랜딩: 키워드 그룹별 대응 페이지(가격 키워드→가격 페이지), 전화·문의 버튼 스크롤 없이, 모바일 3초 로딩, 폼 입력칸 최소화.

## B3. 프리미엄 로그분석 설치·검수·전환 지표

### B3-1. 절차 [공식 네이버 CTS 가이드 navercts.gitbook.io/guide, naver.github.io/conversion-tracking + 실무자 ppcle·지아이코퍼레이션]

1. 비즈채널(웹사이트) 검수 완료 확인
2. 광고주센터 > 도구 > **프리미엄 로그분석** > 신규 신청 (사이트 URL·유형·담당자)
3. 영업일 1~2일 후 **공통 인증키(AccountId)** 발급 — 도구 > 프리미엄 로그 분석 메뉴 또는 안내 메일
4. 스크립트 설치
   - 공통(PV) 스크립트: 모든 페이지 헤더/푸터에 1회
     ```html
     <script src="//wcs.naver.net/wcslog.js"></script>
     <script>
     if (!wcs_add) var wcs_add = {};
     wcs_add["wa"] = "발급받은 AccountId";
     if (window.wcs) { wcs.inflow("example.com"); wcs_do(); }
     </script>
     ```
   - 전환 스크립트: 전환 시점(완료 페이지 또는 완료 처리 함수)에 `wcs.trans(_conv)` — `_conv.type`은 **정해진 영문 유형만** 사용, `value`는 숫자형
     ```html
     <script>
     if (window.wcs) {
       if (!wcs_add) var wcs_add = {};
       wcs_add["wa"] = "발급받은 AccountId";
       var _conv = {}; _conv.type = "lead"; wcs.trans(_conv);
     }
     </script>
     ```
   - 임대형(카페24·메이크샵·고도몰·아임웹·식스샵·큐샵): 관리자 화면에 인증키만 입력하면 기본 전환 자동 설정. HTML 편집 권한 없으면 무료 **설치대행**(FTP 또는 관리자 접근 정보, 외부 접속 차단 시 IP 103.243.200.129 허용).
   - 전환 유형: view_product, add_to_cart, begin_checkout, purchase(value·id 필수), sign_up, lead, schedule(예약), subscribe, view_content, custom001~010. 로컬 업종은 lead(상담 신청)·schedule(예약)·전화 클릭(버튼 클릭 이벤트로 lead 처리)이 핵심.
5. **검수 신청** (자가설치도 필수): 담당자 연락처·검수 대상 전환 유형·테스트용 검색광고 키워드·전환 경로(메뉴명 기준) 제출 → 네이버가 테스트 키워드 클릭 → 전환 수집 검증 → "사용중" 상태 → 데이터 반영. 피드백까지 영업일 2~3일.
6. 자가 검수: 크롬 확장 **네이버 전환 스크립트 어시스턴트**(2025년 하반기 배포)로 광고 클릭 후 페이지뷰·전환(lead 등) 발동·값을 실시간 확인. 흔한 오류: 한글 유형명("구매완료"), value가 "10만원" 같은 문자열, 완료 페이지가 아닌 곳에서 발동.
7. GFA는 별도 전환 설정 필요(raw/07 §1.6). 네이버 애널리틱스 보고서는 별도 사이트 등록·스크립트 설치(공지 29543).

### B3-2. 전환 지표 읽는 법

- 보고서 위치: 광고주센터 > 보고서 > 다차원 보고서 / 대용량 다운로드 보고서. 키워드·소재·시간대·지역·기기별 **전환수·전환매출액**(purchase만 매출 표시)·전환율·전환당 비용.
- 핵심 계산: 전환율(CVR) = 전환수 ÷ 클릭수 / 전환당 비용(CPA) = 광고비 ÷ 전환수 / ROAS = 전환매출 ÷ 광고비. 로컬 리드 업종은 CPA와 "전화 연결률"(스마트콜 통계)을 함께 본다.
- GA4와 숫자가 다른 이유: 기여 모델·추적 기간이 다르고 네이버는 직·간접 전환을 모두 집계. 리포트에 두 지표를 함께 두되 기준을 명시.
- 개선 전 2~4주 기준 수치를 기록해 두어야 개선을 증명할 수 있다(inobean CHECK 1).

## B4. 최적화 루틴과 판단 기준 수치

### B4-1. 주간 루틴 (클라이언트당 30~60분) [실무자 종합]

1. **검색어 리포트 → 제외키워드**: 보고서에서 실제 유입 검색어 확인. 전환 의도 없는 검색어(채용·무료·자격증·타 지역·중고·레시피·뜻)는 그룹/캠페인 제외키워드 등록. 전환 나온 검색어는 정식 키워드로 승격해 일치검색 그룹에 배치.
2. **입찰 조정**: 전환 있는 키워드 순위 유지/상향, 클릭만 있고 전환 0인 키워드는 하향 또는 OFF. 평균 클릭비용 급등 키워드 점검.
3. **소재 A/B**: 그룹당 소재 2~3개 유지, 2주 데이터로 CTR 낮은 소재 교체. 제목에 키워드 삽입 여부·혜택 문구·숫자 비교.
4. **품질지수**: 낮은 키워드는 그룹 분리 또는 소재 문구를 키워드에 맞춤.
5. **확장소재·랜딩 점검**: 전화번호·플레이스·서브링크 정상 노출, 랜딩 링크 깨짐 확인.
6. 스마트콜·예약 통계와 교차 확인(광고 클릭은 늘었는데 전화 연결이 안 늘면 랜딩/응대 문제).

### B4-2. 판단 기준 수치 (1인 대행 초기 가이드, 업종별 조정)

| 지표 | 정상 | 조치 기준 | 비고 |
|---|---|---|---|
| CTR(파워링크 모바일) | 2~5% | 1% 미만 2주 지속 → 소재·확장소재·순위 점검 | [일반] 업종별 편차 큼 |
| 전환율(lead/예약) | 3~10% | 1% 미만 → 랜딩·키워드 의도 불일치 | [일반] 병원·학원은 전화 전환 포함 |
| CPA | 목표 객단가 × 마진율 이내 | 목표 CPA 150% 초과 2주 → 키워드 하향/OFF | 사장님과 목표 CPA를 먼저 합의 |
| 확장검색 비중 | 예산의 30~40% | 전환율이 일치검색 대비 절반 미만이면 상한 축소 | [실무자 beaulead] |
| 무전환 키워드 | 클릭 30회 이상·전환 0 | OFF 또는 입찰 50% 하향 | [일반] |
| 판단 유예 | 첫 1~2주 | 첫 주 데이터로 결론 내리지 않음 | [실무자 uni_on_co] |
| 예산 소진 시각 | 영업시간 종료 즈음 | 오전에 소진되면 시간대 가중치·입찰 하향 | — |

### B4-3. 월간 루틴

- 키워드 5~10개 신규 추가·5개 정리, 시즌 키워드(데이터랩 트렌드) 선반영, 경쟁사 소재 캡처 비교, 전환 스크립트 발동 재검수(사이트 개편 시 필수), 월 리포트(B3 지표 + 플레이스 리포트 통합).

## B5. 공식 대행사 15% 구조와 대대행 파트너

### B5-1. 구조 [공식 faq/88, help.naver.com/service/30016/contents/18143 + 실무자 i-boss·localsenjoy·wearetheads]

- 네이버 **공식 파트너사(공식 대행사)**: 네이버와 제휴된 광고 파트너사. 광고주는 **광고비 외 별도 비용 없이** 이용 가능(네이버 고객센터 원문: "광고비만 지불하고 이용… 광고주가 서비스를 추가로 선택할 경우 비용 발생 가능"). 공식 파트너사 목록: ads.naver.com > 파트너 > 공식 파트너사 안내(실무자 인용: 국내 60여 곳, 해외 5곳, 등급 Premier/Official/Authorized 반기 갱신).

1. **공식 파트너사 목록**(ads.naver.com > 파트너)에서 "대대행/제휴 파트너 모집" 안내가 있는 회사에 문의. 중대형 파트너사(예: 엠서치마케팅·에이엠피엠글로벌·이엠넷·플레이디·인사커뮤니케이션 등 — KAIT 자격 활용 기업 명단 기준)는 대대행 프로그램을 운영하는 경우가 많다.

### B5-3. 대대행 계약 시 확인할 것 [실무자 localsenjoy·i-boss + 일반]

- **정산 방식**: 분리형(광고주가 네이버에 직접 충전, 나는 수수료만) 권장. 통합형(광고비를 대행사 계좌로 받아 충전)은 세무·투명성 문제(raw/07 §6.3)

## C1. C-Rank / D.I.A. / 스마트블록 로직 요약

### C1-1. 공식 정의 [공식]

- **C-Rank** (네이버 검색 고객센터 https://help.naver.com/service/5626/contents/22927): "개별 문서보다는 해당 문서 **출처의 신뢰도**를 평가하는 알고리즘. 블로그의 관심사 집중도(Context), 정보의 품질(Content), 소비 및 생산의 연쇄반응(Chain)을 종합해 해당 블로그가 얼마나 믿을 수 있고 인기 있는지(Creator)를 계산." 2016-07 서치앤테크 공지의 반영 정보 6종: 블로그 컬렉션·네이버 DB·Search LOG·Chain Score·BLOG Activity·BLOG Editor 주제 점수. **점수·등급·가중치는 비공개**이며, 업계의 "최적화/준최적화/저품질 블로그" 등급은 네이버 공식 분류가 아니다.

FAQ: 광고·협찬 글도 명확 표기 시 인용 가능하나 홍보 멘트만 있으면 불리.

### C1-2. 실무 해석 [실무자 종합: seonews, soviss, winnerbrothers, i-boss 66385]

- 순위 ≈ **출처 신뢰도(C-Rank) × 문서 적합도(D.I.A.) × 검색 의도 일치(스마트블록)**. 출처 점수가 낮으면 좋은 글도 경쟁 키워드에서 후보에 못 든다 → 새 블로그는 경쟁 낮은 롱테일부터 반응 이력을 쌓는다(첫 변화까지 평균 4주, 경쟁 키워드는 수개월 — winnerbrothers 자사 데이터).
- C-Rank를 올리는 유일한 공식적 방향: 1~2개 주제 집중 + 꾸준한 발행 + 실제 경험·품질. "매일 쓰면 오른다·이웃 늘리면 오른다·N개월이면 최적화"는 네이버 확인 사실이 아님.
- 의료·금융 등 신뢰 기준 높은 주제는 진입이 느리다.

### C1-3. 사장님 공식 블로그 vs 대행사 블로그 선택 기준

| 기준 | 사장님(업체) 명의 블로그 | 대행사(마케터) 명의 블로그 |
|---|---|---|
| 자산 귀속 | 사장님 자산. 계약 종료 후에도 남음 | 대행사 자산. 종료 시 글이 사라지거나 경쟁사 글이 올라갈 수 있음 |
| C-Rank | 업종 단일 주제로 키우기 쉬움(돈까스집이면 돈까스·재료·매장 이야기만) | 여러 클라이언트를 한 블로그에 쓰면 주제 분산 → C-Rank 불리. 클라이언트별 별도 블로그를 파면 각각 신규 계정 |
| 광고 표기 | 자사 홍보이므로 "광고" 표기 의무는 없으나 **경제적 이해관계(업체 운영자)**를 명시하는 게 AI 브리핑·신뢰에 유리 | 대가를 받고 쓰므로 **모든 글에 "광고/협찬" 표기 의무**(표시광고법, D.I.A.+ 공지) |
| 플레이스 연동 | 솔루션 > 블로그 새소식 연결(20508)로 소식탭 노출 가능. 지도 첨부 글은 블로그 리뷰로 자동 수집(20489) | 지도 첨부 시 블로그 리뷰로는 수집되나 소식탭 연결 불가 |
| 적합 상황 | **기본값**. 콘텐츠 구독 상품은 사장님 블로그에 발행 | 사장님이 블로그를 원치 않거나 병원처럼 의료광고 심의 부담으로 업체 명의 글을 제한하는 경우, 체험단·후기형 콘텐츠 |

**결론**: 구독 상품의 기본은 사장님 명의 블로그(없으면 사장님 네이버 ID로 개설) + 대행사는 원고·사진·발행 대행. 대행사 블로그는 "체험 후기" 보조 채널로만.

### C2-2. 발행 주기 [실무자 + 공식 방향]

- 주 2~3회(월 8~12편)가 구독 상품 표준. 매일 발행은 품질이 떨어지면 역효과. 하루 3~5개 몰아 쓰기·장기 휴면 후 몰아 쓰기·일정한 기계적 패턴은 어뷰징 의심 요소.
- 시간대: 오전 7~9시·점심·저녁 7~9시 예약 발행(alaseo).
- 발행 후 5분 내 검색 노출 확인 습관. 2~3개 연속 누락 시 발행 중단하고 원인 분석(ktr02). 제목을 큰따옴표로 검색해 블로그 탭에 뜨면 아직 살아 있음.
- 발행 3~4일 후 1페이지 미진입 시 제목 서브키워드·첫 문단 수정 후 재확인(h6734131).

### C2-3. 저품질(검색 누락) 회피 규칙

공식 근거가 있는 것:
- AI가 기계적으로 생성·요약한 글의 무분별 발행, 실제 경험 없는 광고성 도배, 무관 키워드 삽입, 과도한 외부 URL, 무관 이미지, 부정확 정보 (네이버 검색 2026-05 가이드)
- 유사문서: 같은 원고·사진을 여러 블로그에 배포하면 유사문서로 묶여 원본 외 미노출 (2025-02 공지, 실무자 ad-manager)
- 대가성 미표시 후기 (D.I.A.+ 공지)

실무자 통념(근거는 경험):
- AI 프롬프트 하나로 계속 돌려 **구조가 동일한 글**(첫 문장만 다른 A/B/C) → 구조적 복제로 탐지
- 상위 노출 글을 AI로 패러프레이징 → 2차 저작물로 간주 위험. 참고 자료는 네이버 밖(제조사 백서·논문·해외 자료)에서 가져와 출처 표기
- 검색 의도와 다른 본문(키워드는 도배, 내용은 청소) → 이탈률 상승

근거 없는 속설(네이버 2016 공식 블로그 인용, dwpolice7 정리): 하루 1~3개만 발행, 상업 블로그에 일상 글 섞기, IP 관리, 복붙 자체 금지, 발행 글 수정 금지, 방문자 500명 유지 — 모두 공식 기준 아님. 단 "정상적인 사람이 썼다고 보기 어려운 속도의 대량 발행"은 별개 문제.

## C3. 사장님 블로그에 대행사가 발행하는 권한 방식

네이버 블로그에는 구글 비즈니스 프로필이나 워드프레스처럼 "공동 작성자/기여자" 권한이 **없다**. 글은 반드시 그 블로그 ID로 로그인해서 써야 한다. 따라서 실무 옵션은 다음 셋이다. [일반 + 실무자]

| 방식 | 절차 | 장점 | 위험·주의 |
|---|---|---|---|
| ① **원고 전달 → 사장님(직원) 발행** | 대행사가 노션/구글독스에 제목·본문·사진(파일명 포함)·장소 첨부 지시·태그를 완성해 전달 → 사장님이 스마트에디터에 붙여넣고 발행. 예약 발행 시간까지 지정 | 계정 공유 없음, 가장 안전. 사장님이 내용 검토 | 사장님이 미루면 주기가 깨짐 → 계약서에 "전달 후 48시간 내 발행, 지연 시 대행사 면책" |
| ② **업무용 네이버 ID 신설 + 대행사 로그인** | 사장님 명의 휴대폰으로 **업무 전용 네이버 ID**를 새로 만들고(개인 ID와 분리), 그 ID로 블로그 개설. 대행사가 로그인 정보를 받아 발행. 2단계 인증 기기는 사장님 폰 + 대행사 승인 | 발행 주기 통제 가능 | 타인 계정 접속은 원칙적으로 약관 위반 영역이므로 **사장님의 서면 위임(계정 이용 위임서)** 필수, 계약 종료 시 비밀번호 변경 확인. 새 로그인 기기 알림이 사장님께 가므로 사전 고지. 여러 클라이언트 계정을 한 PC·IP에서 관리하는 것 자체는 공식 제재 사유가 아니나, 동일 원고를 여러 계정에 올리면 유사문서 |
| ③ **대행사 블로그에 발행 + 사장님 블로그에 링크/새소식 연결** | 대행사 명의 블로그에 "광고" 표기 후 발행, 스마트플레이스 소식탭에 블로그 새소식 연결은 사장님 블로그만 가능하므로 플레이스에는 지도 첨부로 블로그 리뷰 수집만 기대 | 계정 문제 없음 | 자산이 사장님께 남지 않음. C-Rank 분산. 콘텐츠 구독 상품에는 부적합 |

**권장 운영**: ①을 기본으로 하되, 월 1회 이상 사장님이 발행을 놓치면 ②로 전환(위임서 + 계약 조항). 어떤 방식이든 (a) 발행 후 스마트플레이스 > 솔루션 > 블로그 새소식 연결 카테고리에 글이 잡히는지 (b) 글의 장소 첨부가 정확한 플레이스인지 (c) 광고 표기 위치를 대행사가 체크리스트로 검수한다.

발행 파이프라인(자동 생성 콘텐츠 사용 시)의 최소 규칙: 클라이언트별 실제 현장 사진·영상 투입, 글마다 다른 구조·서론, 사장님 검수 1회, 사실 확인(가격·시간), 광고 표기 자동 삽입, 주 2~3회 예약 발행, 발행 후 노출 확인 로그.
