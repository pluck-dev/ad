# 12. 메타(인스타그램·페이스북) 릴스 광고 실무 매뉴얼 — 1인 대행사용

> 작성일: 2026-08-27 · 대상: 로컬 비즈니스(음식점·카페·뷰티샵·병원·학원)와 소규모 이커머스 광고를 실제로 돌려야 하는 초보 1인 대행 운영자
> 표기 규칙: **[공식]** = Meta 공식 문서·정책 원문 또는 플랫폼(카페24·아임웹 등) 공식 도움말에서 확인한 내용. **[실무 통념]** = 국내외 실무자 글·커뮤니티·업계 관례에서 반복되는 기준(수치는 참고용, 계정마다 다름). **[확인 필요]** = 이번 조사에서 원문 확인을 못 했거나 자주 바뀌는 항목 — 실행 전 링크에서 재확인.
> 조사 방법: Meta 비즈니스 지원 센터(한국어)·Meta 광고 표준(transparency.meta.com)·Meta 광고 가이드·Meta 음악 가이드라인·카페24/아임웹 도움말·해외 실무 블로그·국내 세무 블로그. WebSearch 한도 소진으로 일부는 Brave/Playwright 경유. 출처 URL은 각 섹션 말미.

## 1. 계정 구조 정석 — "사장님 명의로 만들고, 대행사는 파트너로"

### 1.1 왜 대행사 계정으로 돌리면 안 되는가

1. **[공식·구조적]** 광고 계정은 그것을 만든 비즈니스 포트폴리오에 귀속되며 다른 포트폴리오로 **이전할 수 없다**(raw 07 §6.4). 대행사 계정으로 만들면 계약 종료 시 픽셀 학습 데이터·맞춤 타겟·소재·광고 히스토리가 전부 대행사에 남고 사장님은 빈손이 된다.
2. **[실무 통념]** 정책 위반·결제 실패 제재는 광고계정 단위가 아니라 **사람·포트폴리오·결제수단·도메인 단위로 연결 추적**된다. 한 클라이언트 사고가 대행사 포트폴리오 전체(다른 클라이언트 포함)로 번진다(raw 04 §3).
3. **[세무]** 대행사 카드로 매체비를 결제하면 매체비가 대행사 매출·매입으로 잡혀 부가세 과세표준이 커지고 정산이 복잡해진다(§9).
4. **[실무 통념]** 담당자 개인 프로필로 광고계정을 만들면 그 사람이 퇴사·계정 정지될 때 접근이 통째로 사라진다.

### 1.3 대행사를 파트너로 추가하고 권한 주기 — 정확한 경로

**[공식]** Meta 비즈니스 지원 센터 "파트너에게 비즈니스 포트폴리오의 비즈니스 자산에 대한 액세스 권한 부여하기" 원문 요지:

> - 비즈니스 포트폴리오에 대한 **전체 관리 권한**이 있는 사람만 파트너를 추가할 수 있다.
> - 파트너(대행사)도 **자기 비즈니스 포트폴리오를 보유**해야 하고, **비즈니스 포트폴리오 ID**를 알려줘야 한다.
> - 아직이라면 포트폴리오에 **2단계 인증**을 설정한다.
> - 경로: **Meta Business Suite 설정 → 왼쪽 메뉴 '사용자' 섹션 → '파트너' → '추가' → '파트너에게 자산에 대한 액세스 권한 부여' → 파트너의 비즈니스 포트폴리오 ID 입력 → 다음 → 공유할 비즈니스 자산과 액세스 권한 수준 선택 → '자산 할당'**
> - 권한은 '전체 관리 권한' 또는 '부분적인 액세스 권한'(콘텐츠 만들기·광고 관리·메시지 응답 등 특정 작업). 전체 관리 권한이 있어도 **파트너는 그 자산을 제3의 비즈니스와 공유할 수 없다**(자산 소유자만 가능).
> - 다른 전체 관리자의 승인이 필요할 수 있다.

**대행사가 준비할 것**
- 대행사 자체 비즈니스 포트폴리오(무료) + 2단계 인증 + **비즈니스 포트폴리오 ID**(설정 → 비즈니스 정보에 표시되는 숫자). 이 ID를 사장님께 카톡으로 보내면 된다. **광고 계정 ID가 아니라 포트폴리오 ID**다.
- 반대 방향도 가능: 대행사 포트폴리오에서 **설정 → 파트너 → 추가 → "파트너에게 내 비즈니스에 자산을 공유해 달라고 요청하기"** → 사장님 포트폴리오 ID 입력 → 사장님이 승인. 사장님이 메뉴를 못 찾을 때 이 방식이 편하다. [공식 메뉴 명칭, 세부 화면은 확인 필요]

**권장 권한 설정 [실무 통념]**

| 자산 | 대행사에 줄 권한 | 이유 |
|---|---|---|
| 광고 계정 | 부분: **광고 관리**(Advertiser) — 필요 시 전체 관리 | 결제 수단 변경·계정 삭제는 사장님만 |
| 페이지 | 부분: 콘텐츠·광고·인사이트·메시지 | 페이지 삭제·관리자 교체 권한은 불필요 |
| Instagram 계정 | 광고·콘텐츠·메시지 | DM 응대 대행 시 메시지 권한 필수 |
| 데이터 세트(픽셀) | 전체 관리 또는 이벤트 관리 | CAPI 설정·이벤트 우선순위 편집에 필요 |
| 카탈로그(이커머스) | 관리 | 상품 광고용 |

- **비밀번호 공유 금지.** 사장님 페이스북 아이디/비번을 받아 로그인하면 Meta가 "비정상 로그인"으로 잡아 계정을 잠그고, 사고 시 책임 소재가 흐려진다.
- 계약 종료 시: 사장님이 **설정 → 파트너 → 대행사 선택 → 삭제**. 데이터는 사장님 포트폴리오에 그대로 남는다. [공식 메뉴 존재 확인]

### 1.4 비즈니스 인증

- **[공식 페이지 존재 확인]** "Meta Business Suite에서 비즈니스 인증하기"(help/2058515294227817). 경로: **설정 → 보안 센터 → 비즈니스 인증 → 시작하기**. [세부 단계는 확인 필요]
- **[실무 통념]** 준비물: 사업자등록증(상호·대표자·주소가 포트폴리오 정보와 일치), 사업자 명의 전화번호 또는 업무용 도메인 이메일(포트폴리오 이메일과 도메인 일치 시 수월), 도메인 인증. 상호 불일치가 가장 흔한 반려 사유.
- 언제 필요한가: 광고 지출 한도 상향, 리드 광고·메시지 API 등 일부 기능, 정지 시 복구 심사에서 신뢰도 근거. 온보딩 첫 주에 해두는 것이 정석.

### 1.5 온보딩 30분 스크립트 (사장님과 화면 공유)

1. 사장님 페이스북 로그인 → 2단계 인증 확인
2. business.facebook.com → 포트폴리오 생성(5분)
3. 페이지·인스타 연결(5분)
4. 광고 계정 생성 → 결제 카드 → 사업자등록번호(10분)
5. 설정 → 파트너 → 추가 → 대행사 포트폴리오 ID 붙여넣기 → 자산 4종 할당(5분)
6. 보안 센터 → 비즈니스 인증 신청(5분, 심사는 수일)
7. 대행사 화면에서 광고 관리자에 클라이언트 광고계정이 뜨는지 확인 → 카톡으로 "연결 완료" 캡처 공유

## 2. 픽셀(데이터 세트)·전환 API(CAPI) 설치

> 원칙: **추적 없이 광고를 켜지 않는다.** 2026년 기준 픽셀만으로는 iOS·광고차단으로 신호가 30~40% 빠진다는 것이 통념이고, Meta 자체 발표로 CAPI 병행 시 결과당 비용이 17.8% 낮아진다(raw 07 §2.3). 첫 견적에 "전환 추적 셋업"을 별도 항목으로 넣는다.

### 2.1 용어 정리
- **데이터 세트(Dataset)** = 예전 "픽셀". 이벤트 관리자에서 만든다. 픽셀 ID = 데이터 세트 ID(숫자 15~16자리).
- **픽셀(브라우저 이벤트)**: 방문자 브라우저에서 Meta로 전송. **전환 API(서버 이벤트)**: 사이트 서버(또는 호스팅사 서버)에서 Meta로 직접 전송.
- **표준 이벤트**: PageView, ViewContent, AddToCart, InitiateCheckout, Purchase, Lead, Contact, CompleteRegistration, Schedule 등. 로컬 비즈니스는 **Lead / Contact / Schedule** 3개면 충분.
- **중복 제거**: 픽셀과 CAPI가 같은 행동을 둘 다 보내면 **동일 event_name + event_id**로 Meta가 하나로 합친다. [공식 개념]

### 2.2 플랫폼별 설치

#### A. 카페24 (쇼핑몰) — 가장 쉬움
**[공식: 카페24 Help Center "메타 채널 - 픽셀/전환 API 이벤트 설정이 무엇인가요?" 및 "Facebook 채널 픽셀/전환 API 설정"]**
- 카페24 관리자 → **판매채널(마켓/채널 관리) → Facebook(메타) 채널 → Facebook 로그인** → 사장님 Facebook으로 로그인 → **비즈니스 계정(포트폴리오)·페이지·연결 인스타·광고계정·픽셀·커머스 계정 선택** → 고급 매칭 자동 활성화 → 도메인 확인 [실무 가이드(brunch) 경로, 공식 도움말과 일치]
- 채널 설정이 끝나면 **픽셀이 자동 설치**되고, 장바구니·구매 같은 **브라우저 이벤트**와 카페24 서버에서 Meta 서버로 보내는 **서버 이벤트(전환 API)**가 함께 전송된다. 액세스 토큰을 따로 발급받을 필요가 없다. [공식]
- 자동 전송 표준 이벤트: PageView, ViewContent, AddToCart, InitiateCheckout, Purchase [실무 가이드]
- 대안: 카페24 앱스토어(관리자 → 애플리케이션 → 앱스토어)에서 "Facebook 픽셀 연동"/"Meta 광고 연동" 류 앱 설치 → 픽셀 ID 입력. 이 경우 **중복 이벤트가 뜨면 앱의 '중복 방지' 옵션**을 켠다. [실무 가이드]
- 함정: 채널 연동과 앱, 그리고 직접 스크립트 삽입을 **동시에 하면 이벤트가 2~3배로 잡힌다.** 한 가지 방법만.

#### B. 아임웹 (랜딩·소규모 쇼핑몰) — 로컬 비즈니스 표준
두 가지 방법 중 **하나만** 쓴다. [아임웹 FAQ + 실무 가이드]
- **방법 1(가장 간단)**: 아임웹 관리자 → **환경설정 → SEO → "Facebook(Meta) 픽셀 ID"** 칸에 픽셀 ID 입력 → 저장. PageView만 자동. 리드/문의 이벤트는 아래 방법 2 또는 이벤트 설정 도구로.
- **방법 2(전환 API까지)**: 관리자 → **광고 캠페인 관리 → 데이터 연결 → Facebook & Instagram** → 광고계정·페이지 연결 → 비즈니스 관리자 → **"픽셀 & 전환 API"** 칸에서 픽셀 선택 → 카탈로그(쇼핑몰만). 아임웹이 **액세스 토큰 없이 자동으로 전환 API를 연결**한다. FBE 연결 오류가 나면 Meta 포트폴리오에 페이지·광고계정·픽셀이 먼저 존재하는지 확인. [아임웹 FAQ idx 72112·71239 요지]
- **방법 3(개발자)**: 환경설정 → SEO → 고급 설정 → 공통 코드 삽입 → 헤더에 픽셀 기본 코드. 문의 폼 완료 페이지에 `fbq('track','Lead')` 삽입.
- 검증: Meta Pixel Helper 크롬 확장에서 픽셀 ID·PageView 표시 확인 → 이벤트 관리자 테스트 이벤트.

#### C. 네이버 스마트스토어 — 픽셀 설치 불가, 우회만 가능
- **[실무 통념]** 스마트스토어는 판매자가 임의 스크립트를 넣을 수 없으므로 픽셀·CAPI 설치가 안 된다. (네이버 커머스솔루션마켓에 Meta 연동 솔루션이 있는지는 **[확인 필요]** — 있더라도 구매 이벤트 전송 여부를 직접 검증할 것.)
- 대안 4가지:
  1. **브릿지 랜딩**: 아임웹/자체 페이지에 상품 소개 + "스토어에서 구매" 버튼 → 버튼 클릭을 `Lead` 또는 커스텀 이벤트로 잡아 최적화. 랜딩에는 리뷰·가격·배송 정보를 넣어 이탈을 줄인다.
  2. **UTM + 스마트스토어 통계**: 광고 링크에 `utm_source=meta&utm_medium=paid_social&utm_campaign=…`을 붙이고 스마트스토어센터 **통계 → 마케팅 채널**에서 유입·결제를 본다. Meta 쪽 최적화는 안 되지만 리포트는 가능.
  3. **트래픽 목표 + 랜딩 페이지 조회 최적화**로 돌리고, 스토어 결제 수로 ROAS를 수동 계산.
  4. 이커머스 클라이언트라면 **자사몰(카페24/아임웹) 개설을 제안**하는 것이 근본 해법. 메타 광고로 스토어에 보내는 구조는 최적화 신호가 없어 예산 효율이 낮다.

#### D. 자체 개발 사이트(Next.js·워드프레스 등)
- 픽셀: `</head>` 앞에 기본 코드, 또는 GTM 태그(2026-04 Meta 공식 GTM 템플릿, raw 07 §2.2).
- CAPI 3가지(raw 07 §2.3): **CAPI Gateway**(2~4h, Meta만 쓸 때) / **서버사이드 GTM + Stape**(4~8h, 월 $10~50, 다채널이면 추천) / **직접 구현**(Marketing API `/{dataset_id}/events`).
- 필수: event_id를 픽셀·서버 양쪽에 동일하게, fbp/fbc는 해시하지 말고, 이메일·전화는 SHA256 해시. EMQ(이벤트 매칭 품질) 목표 Lead 7+, Purchase 8+.

### 2.3 이벤트 설계 (로컬 비즈니스 기준)

| 클라이언트 | 핵심 이벤트 | 어디서 발생 |
|---|---|---|
| 음식점·카페 | `Contact`(전화 클릭), `Schedule`(네이버 예약 버튼 클릭), 인스턴트 양식 리드 | 랜딩 버튼 클릭 / 리드폼 |
| 뷰티샵·네일 | `Lead`(상담 신청), `Schedule`(예약) | 랜딩 폼 완료 페이지 |
| 병원·의원 | `Lead`(상담 예약), `Contact`(전화) — 진료 과목·증상 데이터는 보내지 않음(개인 건강 정보) | 랜딩 |
| 학원 | `Lead`(상담·레벨테스트 신청), `CompleteRegistration` | 랜딩 |
| 이커머스 | `ViewContent`→`AddToCart`→`InitiateCheckout`→`Purchase`(value·currency 필수) | 쇼핑몰 자동 |

- **이벤트 설정 도구(코드 없이)**: 이벤트 관리자 → 데이터 세트 → 이벤트 추가 → "코드 없이 새 이벤트" → 사이트 URL 입력 → 버튼/URL 규칙으로 Lead·Contact 지정. 아임웹 방법 1과 조합하면 개발 없이 리드 이벤트를 만들 수 있다. [공식 기능]
- 전화 클릭: `tel:` 링크 클릭을 `Contact`로 잡는다(이벤트 설정 도구 또는 GTM 클릭 트리거).

### 2.4 이벤트 관리자로 검증

1. **이벤트 관리자 → 데이터 세트 → '테스트 이벤트' 탭** → 사이트 URL 입력 → 브라우저에서 직접 행동(폼 제출) → 실시간으로 이벤트가 뜨는지, 서버 이벤트와 브라우저 이벤트가 **"중복 제거됨"**으로 묶이는지 확인. [공식 기능]
2. **Meta Pixel Helper**(크롬 확장): 페이지에서 픽셀 ID·발생 이벤트·경고 확인.
3. **개요 탭 → 이벤트 매칭 품질(EMQ)** 점수 확인. 4점 이하이면 고급 매칭(이메일·전화 전송) 켜기.
4. **진단 탭**의 경고를 주 1회 확인(동일 이벤트 중복, 매개변수 누락).

### 2.5 도메인 인증
- 경로: **비즈니스 설정 → 브랜드 안전 및 적합성 → 도메인 → 추가** → 인증 방법 3가지 중 택 1: **메타 태그**(사이트 `<head>`에 삽입 — 아임웹은 SEO 고급 설정·카페24는 디자인 편집), **DNS TXT 레코드**, **HTML 파일 업로드**. [공식 기능]
- 왜: 링크 광고의 소유권 증명(사칭 방지), 집계 이벤트 측정 설정의 전제, 광고 링크 편집 권한. 클라이언트 도메인은 **클라이언트 포트폴리오에서 인증**한다.

### 2.6 집계 이벤트 측정(AEM)
- **[공식 기능·실무 통념]** iOS 14.5 이후 도메인당 우선순위 이벤트 8개를 지정하는 기능. 경로: 이벤트 관리자 → 데이터 세트 → **집계 이벤트 측정 → 웹 이벤트 구성 → 도메인 선택 → 이벤트 관리**. Purchase(값 최적화) > Lead > Contact > ViewContent > PageView 식으로 배치.

### 3.2 리드 광고(인스턴트 양식) vs 메시지 광고 vs 랜딩 페이지

| | 인스턴트 양식(리드 광고) | 메시지 광고(인스타 DM·메신저) | 랜딩 페이지 |
|---|---|---|---|
| 장점 | 앱 안에서 이름·전화 자동 입력 → **CPL 가장 낮음**, 픽셀 불필요 | 대화형, 젊은 타겟·뷰티에 자연스러움, 예약 전환율 높음 | 정보량·신뢰(후기·가격표), 픽셀 최적화·리타게팅 가능 |
| 단점 | 리드 품질 낮음(자동 입력으로 실수 클릭), **5분 내 응대 못 하면 죽은 리드** | DM 응대 인력 필요, 야간 문의 누락, 전환 측정이 '대화 시작' 수준 | 제작 비용·시간, 픽셀 세팅 필수 |
| 품질 높이는 법 | "자세한 양식"(추가 질문 2~3개: 희망 시술/시간대), 검토 화면 추가, 조건부 질문 | 자동 인사말 + 빠른 답변 템플릿, 영업시간 외 자동응답 | 폼을 페이지 상단에, 3필드 이하 |
| 카카오톡 연결 | 불가 | **불가(카카오는 Meta 메시지 목적지 아님)** → 대안: 리드폼 완료 화면 "카카오 채널 바로가기" 버튼 / 랜딩에 카카오 채널 버튼 / 리드 수집 후 알림톡 발송(§6) | 카카오 채널 버튼 배치 가능 |
| 추천 업종 | 병원·학원·인테리어·보험 | 뷰티샵·네일·카페 이벤트·소규모 쇼핑몰 | 이커머스·고가 상담(성형·치과·유학) |

**[실무 통념]** 로컬 계정의 기본값 = **리드 캠페인(인스턴트 양식) 1개 + 참여(메시지) 캠페인 1개**를 같은 소재로 2주 돌려 CPL·응답률을 비교한 뒤 하나로 몰아준다.

**인스턴트 양식 만들 때** [공식 기능]
- 양식 유형: "더 많은 볼륨"(빠른 제출) vs "더 높은 의도"(검토 단계 추가) → 병원·학원은 **높은 의도** 권장.
- 필드: 이름·전화번호(자동 입력) + 맞춤 질문 1~2개(객관식: "관심 시술", "희망 상담 시간").
- **개인정보처리방침 URL 필수**(사장님 사이트 또는 노션 페이지도 가능). 없으면 저장 안 됨.
- 완료 화면: "24시간 내 연락드립니다" + 전화 버튼 또는 카카오 채널 링크.
- 리드는 **페이지 → 게시 도구 → 인스턴트 양식**에서 CSV 다운로드. **[공식·확인 필요]** 다운로드 가능 기간이 제한(통상 90일)되므로 §6 자동 전달 필수.

### 3.3 타게팅

**위치(반경)** — **[공식 수치는 실무 글 인용]** 국제(한국 포함) 반경 최소 1km, 최대 70km. 주소 핀 찍고 반경 지정, "이 위치에 거주하는 사람"과 "최근 이 위치에 있던 사람" 구분 가능.

| 업종 | 권장 반경 [실무 통념] | 메모 |
|---|---|---|
| 동네 음식점·카페 | 2~5km | 배달 반경 또는 도보·차량 15분 |
| 뷰티샵·네일·왁싱 | 3~10km | 지하철 노선 따라 확장 |
| 병원·의원 | 5~15km(전문과는 시·도 단위) | 타 지역 원정 수요 있는 과목은 넓게 |
| 학원 | 2~5km(초중등) / 10~20km(입시·성인) | 학군·통학 가능 거리 |
| 반경이 너무 좁으면 | 오디언스가 작아 CPM 급등·학습 불가 | 2~3만 명 미만이면 넓히기 |

**연령·성별**: 서비스 실구매층으로만. 미용 시술·체중 관리·성형 광고는 **18세 이상 타게팅이 정책상 필수**(§4.5).

**관심사·행동**: 로컬 소액 계정에서는 **관심사 세분화가 거의 효과 없다**(오디언스가 위치로 이미 좁음). 위치+연령만 잡고 소재로 타게팅하는 것이 2026년 표준. [실무 통념]

**Advantage+ 오디언스 사용 기준** [실무 통념 + Meta 설명 요지]
- Advantage+ 오디언스는 입력한 연령·관심사를 "제안"으로만 쓰고 **위치와 최소 연령만 강제**한다.
- 켜는 경우: 픽셀에 전환 데이터가 쌓였을 때(월 50건+), 이커머스, 반경이 넓은 병원.
- 끄는(원본 오디언스 사용) 경우: 반경 5km 이하 로컬, 리드 품질이 문제일 때(해외 실무자들은 로컬 리드 광고에서 Advantage+ 끄고 수동 타게팅이 품질 낫다고 보고), 성별 제한이 꼭 필요한 서비스.
- Advantage+ 오디언스를 켜도 **연령 상한이 확장**될 수 있으므로 18+ 정책 대상 업종은 "연령 제어"로 최소 연령 18 고정.

**맞춤 타겟·유사 타겟**
- 리타게팅용 맞춤 타겟 3종(§5.4): 영상 시청자(25%/50%/75%), 인스타 참여자(365일), 사이트 방문자(30/90/180일), 리드폼 열람·제출자.
- 유사 타겟(1%)은 소스 1,000명 이상일 때만 의미. 소액 로컬은 초기 3개월간 불필요.

### 3.4 예산 — 일 1만~5만 원의 현실

**[공식] 학습 단계**: "일반적으로 광고 세트가 마지막으로 대폭 수정되고 **한 주가 지난 후 약 50건의 결과**가 발생하면" 학습이 끝난다. 결과가 부족하면 "제한된 머신 러닝"으로 표시된다. Shops 광고는 웹 구매 17건 + Meta 구매 5건.

이걸 예산으로 환산하면:

| 최적화 이벤트 | 국내 로컬 CPL/CPA 통념 | 주 50건에 필요한 주 예산 | 일 예산 환산 |
|---|---|---|---|
| 리드(인스턴트 양식) | 5,000~20,000원 | 25만~100만 원 | **3.5만~14만 원** |
| 메시지(대화 시작) | 3,000~10,000원 | 15만~50만 원 | 2만~7만 원 |
| 랜딩 페이지 조회 | 300~1,000원 | 1.5만~5만 원 | 2천~7천 원 |
| 구매(이커머스, 객단가 3~5만) | 15,000~40,000원 | 75만~200만 원 | 10만~30만 원 |

**결론 [실무 통념]**
- **일 1만 원**: 어떤 전환 최적화도 학습 완료 못 함. → 참여(메시지) 또는 트래픽(랜딩 조회)로 돌리고, 리타게팅 모수(영상 시청자)를 쌓는 단계로 본다. 광고세트 1개, 소재 3개.
- **일 2~3만 원**: 메시지 목표는 학습 가능. 리드 목표는 '제한된 머신 러닝' 상태로 돌아가지만 CPL이 목표 안이면 그대로 둔다(제한이어도 광고는 나간다). 광고세트 1개, 소재 4~6개.
- **일 5만 원**: 리드 목표 학습 가능 구간 진입. 테스트 세트(1만)+스케일 세트(4만) 분리 가능.
- 광고세트를 쪼갤수록 세트당 결과가 줄어 학습이 더 어려워진다 — **[공식]** "광고 수를 늘리지 마세요… 유사한 광고 세트를 합치면 머신 러닝도 통합할 수 있습니다."
- 사장님에게 첫 미팅에서 말할 문장: "메타는 일주일에 문의 50건은 받아야 '누구에게 보여줄지'를 배웁니다. 하루 1만 원이면 그 학습이 끝나지 않으니, 처음 한 달은 데이터를 사는 기간이라고 보셔야 합니다."

**학습 단계 유지 규칙** [공식 + 실무 통념]
- **[공식]** 학습 중 광고·광고세트·캠페인을 수정하면 학습이 리셋된다. 예산을 너무 적게/크게 잡거나 자주 바꾸면 재진입한다. 광고 관리자 열에 "최근 영향이 큰 변경"을 추가해 마지막 대폭 변경 시점과 그 이후 결과 수를 본다.
- **[실무 통념]** 리셋되는 변경: 타게팅, 소재 추가/삭제, 최적화 이벤트, 입찰 전략, **예산 20% 초과 변경**, 7일 이상 일시중지. 안전한 변경: 예산 20% 이내, 이름 변경, 일정 조정, 7일 미만 일시중지.

### 3.5 캠페인 구조 — 테스트 20% / 스케일 80% (Ben Heath 방식)

```
[캠페인 A] 스케일 — 예산 80%
  └ 광고세트 1: 위치 반경 + 연령 (Advantage+ 오디언스 켜거나 끄기, 하나로 고정)
      └ 검증된 소재 3~5개 (승자만)
[캠페인 B] 테스트 — 예산 20%
  └ 광고세트 1: 동일 타게팅
      └ 신규 소재 3~5개 (매주 교체)
```
- 승자 판정(§5.2)을 통과한 소재만 A로 복사. B는 매주 새 훅으로 채운다.
- 캠페인 예산 최적화(Advantage 캠페인 예산)는 광고세트가 1개면 의미 없다 → 광고세트 예산으로 시작.
- 리타게팅은 예산이 일 3만 원 이상일 때 **캠페인 C(예산 10~15%)**로 분리, 그 전엔 A에 맞춤 타겟을 "포함"만.
- 입찰: 처음엔 **최고 볼륨(최저 비용)**. CPL이 안정된 뒤 "결과당 비용 목표"를 검증 CPL의 1.2배로 시험.
- 노출 위치: **Advantage+ 노출 위치**로 두되 릴스 전용 소재라면 9:16 하나만 넣어도 피드·스토리에 자동 변환된다. 오디언스 네트워크는 로컬 리드 광고에서 저품질 리드 원인이 되면 제외.

### 4.1 기술 규격 **[공식 — Meta 광고 가이드 "Instagram Reels 동영상 광고"]**

| 비율 | **9:16** |
| 해상도 | **1440×2560 픽셀** 권장(최소 1080×1920은 실무 기준) |
| 길이 | 0초~15분 (실무: **6~15초 훅형 / 최대 30초**) |
| 파일 | MP4, MOV / 최대 4GB / H.264, 정사각 픽셀, 고정 프레임 속도, 프로그레시브, AAC 128kbps+ 스테레오 |
| 기본 문구 | **44자**(초과분은 잘림) |

- 실무 환산(1080×1920 기준): 상단 약 270px, 하단 약 670px, 좌우 약 65px 비우기. 자막은 화면 세로 중앙~중앙 아래 (y 900~1,200px)에 배치.
- 소리 없이 봐도 이해되게 자막 필수. 국내 릴스 시청의 다수가 무음 시작이라는 것이 통념.

### 4.2 첫 3초 훅 — 소재 성과의 60~70%
- 구조: **훅(0~3초) → 문제/공감(3~8초) → 해결·증거(8~20초) → CTA(마지막 3초)** (raw 07 §3.1).
- 훅 유형 10개(사장님 매장용):
  1. 결과 먼저: "이게 2만 원짜리 파스타입니다" (음식 클로즈업 즉시)
  2. 가격 공개: "강남 속눈썹 연장, 진짜 가격 공개합니다"
  3. 질문: "왜 이 동네 사람들은 여기서만 커피를 살까요?"
  4. 숫자: "3개월에 137명이 등록한 이유"
  5. 반전: "이 가게, 간판이 없습니다"
  6. 지역명: "○○동 사시는 분만 보세요"
  7. 비포→애프터(정책 범위 내): "이 상태에서 → 40분 뒤"
  8. 사장님 얼굴+한 문장: "제가 직접 굽습니다"
  9. 손님 리액션: 첫 입 먹는 순간
  10. 실수/솔직: "솔직히 저희 웨이팅 깁니다. 그래도 오는 이유는…"
- Ben Heath: **풀 영상 1개당 훅 10개를 요청해 영상 2개로 광고 20개**(raw 02 §1-14). 90%는 훅 이후를 안 본다.

### 4.3 음원 저작권 — 광고엔 상업용 라이선스 음원만

- **[공식] Meta 음악 가이드라인**: 음악을 **상업적 또는 개인적이지 않은 목적으로 사용하려면 별도 권리 허가**가 필요하다. 권리자가 문제 삼으면 콘텐츠가 **차단·음소거·삭제**될 수 있고, 음악 밀도가 높을수록 제한 가능성이 커진다.
- **[실무 통념]** 인스타 앱의 인기 음원(상업 음원)은 **개인 계정용 라이선스**라 광고 소재에 못 쓴다. 비즈니스 계정은 앱에서 음원 선택 시 이미 "로열티 프리" 목록만 뜬다. 인기 음원을 넣어 올린 오가닉 릴스를 **"게시물 홍보"로 부스트하면 음원 문제로 거부되거나 음소거**된다.
- 광고용 음원 소스: **Meta Sound Collection**(facebook.com/sound/collection, 무료·광고 사용 가능), 유료 라이선스(Epidemic Sound·Artlist 등 — 소셜 광고 사용 범위 포함 플랜), 국내 음원 라이선스(멜론 등은 불가; 유튜브 오디오 라이브러리는 유튜브 외 사용 조건 확인), 자체 제작(Suno 등 AI 생성물은 서비스 약관의 상업 사용 조항 확인).
- 계약서: "광고 소재에 사용되는 음원·폰트·이미지는 대행사가 상업 사용 라이선스를 확보한 것만 사용하며, 클라이언트가 제공한 소재의 권리는 클라이언트가 보증한다."

### 4.6 정책 제한 — 의료·뷰티 (Meta 광고 표준 원문 기준)

**개인 속성(Privacy Violations and Personal Attributes) [공식]**
- 광고는 인종·민족·종교·**나이**·성적 지향·성 정체성·**장애·신체/정신 건강 상태**·재정 상태·투표·범죄 기록·이름 등 **개인 속성을 단정하거나 암시해서는 안 된다.** 사용자나 가족의 의료 정보를 아는 것처럼 암시하는 것 금지.
- 원문 예시:
  - 위반: "Do you have diabetes?"(당뇨 있으세요?), "Meet other seniors"(다른 노인들을 만나세요), "Are you bankrupt?"
  - 허용: "Bulimia counseling available"(폭식증 상담 가능), "Meet seniors"
- 한국어 적용: "탈모 고민이시죠?" ✗ → "탈모 상담 가능" ○ / "살 빼야 하는 당신" ✗ → "체형 관리 프로그램 안내" ○ / "40대라면 꼭" ✗ → "40대에게 인기 있는" ○ / "우울하신가요?" ✗ → "심리 상담 센터" ○. 2인칭 단정("당신은 ~하다")을 3인칭 서비스 설명으로 바꾸면 대부분 통과한다.

**건강·웰니스(Health and Wellness) — 개인 건강·외모 [공식]**
- **체중 감량/증량 제품, 미용 시술, 건강보조식품 광고는 18세 이상에게만** 타게팅해야 한다.
- 금지: 외모에 대한 **열등감 표현**(부정적·공격적 묘사), **특정 신체 부위 클로즈업·살 꼬집기** 같은 신체 수치 이미지, 불치 질환(당뇨·암·자폐·HIV 등) **완치 주장**(증상 관리는 가능), **기간을 못 박은 결과 약속·과장 표현**.
- 허용(18+ 타게팅 시): 체중 감량 제품의 결과 묘사는 **결과까지 걸린 기간을 명확히 표기**할 때, **일반 미용 제품·시술·수술의 비포애프터 변신 묘사**(가슴 확대·코 성형·필러 등 예시 명시).
- 연령 제한 미적용: 피트니스 서비스, 일반 식품, 메이크업·크림 같은 비영구 미용 제품, 치과 제품.
- 실무 번역: 뷰티샵 비포애프터는 **얼굴/시술 부위 전체 샷·동일 조건·과장 없는 문구·18+ 타게팅**이면 가능. "-10kg 2주" ✗, "3개월 프로그램 후 변화(개인차 있음)" ○. 배 살 꼬집는 영상 ✗.

**허용되지 않는 비즈니스 관행 [공식 카테고리, 원문 미확인]**: 오해 소지 주장, 비현실적 결과, 가짜 희소성·마감 등이 "Fraud, Scams and Deceptive Practices" 하위에 있다. [확인 필요]

**한국 의료광고법(병원·의원 클라이언트) [법령 — 원문 재확인 필요]**
- 의료법 제56조: 치료 경험담·전후 사진 등 **소비자를 현혹할 우려가 있는 광고**, 비교·비방, 근거 없는 효과 보장, 심의 미필 광고 등 금지. 제57조: **의료광고 사전심의** — 2018-09-28부터 SNS 등 인터넷 매체 중 **직전 3개월 일평균 이용자 10만 명 이상 매체**는 사전심의 대상(인스타그램·페이스북 포함). 심의 기관: 대한의사협회·치과의사협회·한의사협회 의료광고심의위원회.
- 실무: 병원 릴스 광고 소재는 **심의필 번호를 받은 뒤** 집행. 심의 없이 돌리면 광고주(병원)가 처벌 대상이고 대행사도 공범 리스크. 계약서에 "의료광고 심의는 클라이언트 책임, 심의 전 집행 요청 거절권" 명시.
- Meta 정책과 의료법은 **별개**다. Meta가 승인해도 의료법 위반일 수 있다(예: 환자 치료 경험담 릴스).

## 5. 최적화 루틴

### 5.1 일 체크 5분 (아침 10시, 광고 관리자 열 프리셋 저장)

열 구성: 지출 / 노출 / **CPM** / **CTR(링크)** / 결과 / **결과당 비용(CPL·CPA)** / 빈도 / 3초 재생 비율(훅률) / ThruPlay / 최근 영향이 큰 변경.

| 확인 | 정상 | 조치 |
|---|---|---|
| 지출이 일 예산 대비 90% 이상 소진되는가 | 예 | 아니오 → 오디언스 너무 좁음·소재 거부·결제 실패·입찰 상한 확인 |
| CPM이 전일 대비 ±30% 안인가 | 예 | 급등 → 빈도·오디언스 포화·경쟁 시즌(명절·연말) 확인 |
| CTR(링크)이 기준선 위인가 | 릴스 0.8~1.5% [실무 통념] | 0.5% 미만 이틀 → 소재 킬 후보 |
| CPL이 목표 안인가 | 목표 = 사장님 객단가 × 전환율 역산 | 목표 1.5배 초과 3일 → 소재/양식 점검 |
| 학습 상태 | 머신 러닝 → 활성 | '제한됨'이 2주 지속 + CPL 정상이면 그대로 둠 |
| 소재 거부·계정 경고 | 없음 | 있으면 §8 |

**국내 릴스 광고 벤치마크 [실무 통념, 2025~26 커뮤니티 기준 — 계정별 편차 큼]**: CPM 4,000~12,000원, CPC 200~800원, CTR(링크) 0.7~1.5%, 훅률(3초 재생/노출) 25~35%, 리드 CPL 5,000~20,000원, 메시지 대화당 3,000~10,000원. 사장님에게는 "우리 계정의 첫 2주 수치"를 기준선으로 삼는다고 설명하고 외부 수치는 참고만.

### 5.2 48~72시간 킬룰 (테스트 캠페인 소재 단위)

전제: 소재당 **1,000 노출 이상 + 48시간** 경과 후 판정. 그 전엔 손대지 않는다(학습 리셋). [실무 통념, raw 07 §3.1 Chatterbuzz 기준을 국내 소액에 맞게 조정]

| 훅률(3초/노출) | CPL(목표 대비) | 판정 |
|---|---|---|
| ≥30% | ≤100% | **승자** → 스케일 캠페인으로 복사 |
| ≥25% | 100~130% | **개선** → 훅 유지, CTA·자막·길이만 변형해 재테스트 |
| <25% 또는 CTR<0.5% | 어떤 값이든 | **종료** |
| 어떤 값이든 | >150% 3일 지속 | **종료** |

- 소액(일 1~2만 원)이면 1,000 노출까지 3~4일 걸릴 수 있다 → 판정 주기를 72시간~5일로 늘린다.
- 소재를 끌 땐 광고 단위에서 **끄기(일시중지)**만. 삭제하면 데이터가 사라진다.

### 5.3 주간 루틴 (금요일 30분)

1. 테스트 캠페인 소재 판정 → 승자 복사, 패자 끄기
2. **신규 소재 3~5개 업로드**(주 3~5개가 소액 계정 현실, raw 07 §3.3)
3. 빈도 확인: **[실무 통념]** 콜드 오디언스 빈도 **2.5~3 초과**, 리타게팅 **5~6 초과** 또는 CTR이 2주간 20% 이상 하락하면 소재 피로 → 교체. 반경 5km 소액 로컬은 오디언스가 작아 2~3주면 피로가 오므로 **2~3주마다 콜드 소재 전면 교체**.
4. 광고 관리자 **"크리에이티브 피로도 추천"** 알림 확인 [공식 기능]
5. 리드 품질 피드백 사장님께 받기(연락 됨/노쇼/허수 비율) → 양식 질문 조정
6. 3줄 주간 요약 카톡 발송(§7)

### 5.4 리타게팅 세팅 (예산 일 3만 원 이상부터 분리)

맞춤 타겟 만들기: 광고 관리자 → 타겟 → 맞춤 타겟 만들기 [공식 기능]

| 소스 | 설정 | 기간 | 소재 |
|---|---|---|---|
| 동영상 | 릴스/영상 **50% 이상 시청자** (25%는 너무 넓음) | 30~90일 | 후기·가격·이벤트(전환형) |
| Instagram 계정 | 계정과 상호작용한 모든 사람 / 광고 저장·공유 | 90~365일 | 예약 CTA |
| 웹사이트 | 픽셀 전체 방문자 / Lead 완료자 **제외** | 30일 | "아직 고민 중이세요?" FAQ |
| 리드 양식 | 양식 열었지만 미제출 | 90일 | 혜택 리마인드 |
| 고객 리스트 | 사장님 기존 고객 전화번호(동의 받은) 업로드 → 제외 또는 재방문 | — | 재방문 이벤트 |

- 리타게팅 캠페인은 참여 목표(메시지) 또는 리드 목표로, 예산 10~15%, 빈도 5 넘기면 소재 교체.
- 기존 고객 리스트 업로드는 개인정보 처리 위탁·제3자 제공 동의 확인 후(raw 04 §7).

### 5.5 스케일 규칙

- **[실무 통념, 다수 소스 일치]** 예산 증액은 **20% 이내, 2~3일 간격**. 20% 넘게 올리면 학습 리셋 가능성. 하루에 2배로 올리지 않는다.
- 증액 조건: 직전 3일 CPL이 목표 이하 + 빈도 3 미만 + 학습 '활성'.
- 감액도 같은 규칙(20%/2일). 급감은 게재량이 회복 안 되는 원인.
- 수평 확장: 예산 대신 **반경 확장(5→8km)** 또는 **승자 소재의 훅 변형 추가**로 도달을 넓힌다.
- Ben Heath: "잃어도 되지만 신경 쓸 만큼"의 예산에서 시작, 수익성 확인 후에만 증액, 확장 시 ROAS 하락은 정상(raw 02 §1-14).
- 월 예산 100만 원 계정이 300만 원까지 가는 데 6~8주가 현실적 속도.

## 6. 리드 후속 — "5분 안에 전화하지 않으면 광고비를 버린다"

### 6.1 데이터 [연구]
- **Lead Response Management Study(InsideSales/MIT, 반복 인용되는 원 연구)**: 5분 내 응답 시 30분 후 대비 **연결 확률 100배, 자격 검증(상담 성사) 확률 21배**. 5분→10분 사이에 자격 검증 확률이 **4배 하락**. 첫 1시간이 지나면 연결 성공이 10배 이상, 검증 성공이 6배 이상 떨어진다. 20시간 이후 연락은 오히려 역효과. 요일은 수·목, 시간대는 오전 8~9시·오후 4~6시가 가장 좋았다.
- **HBR "The Short Life of Online Sales Leads"(2011)**: 미국 기업 2,241곳 감사 결과 대다수가 리드에 충분히 빨리 응답하지 않음(평균 응답 시간 42시간, 1시간 내 응답 37%라는 수치가 널리 인용되나 이번 조사에서 본문은 확인 못 함 [확인 필요]).
- 국내 로컬 적용 [실무 통념]: 인스턴트 양식 리드는 "지나가다 눌러본" 사람이 많아 **10분 안에 문자/알림톡 1통 + 30분 안에 전화**가 안 되면 절반이 사라진다. 사장님이 직접 응대 못 하면 **자동 알림톡/문자**로 첫 접점만이라도 5분 안에.

### 6.2 수동(최소) 방식
- 페이지 → 게시 도구(또는 Meta Business Suite → 모든 도구 → 인스턴트 양식) → 양식 선택 → **다운로드(CSV)**. [공식 기능]
- **[공식·확인 필요]** 리드 데이터는 제한 기간(통상 90일) 후 다운로드 불가 → 반드시 외부 저장.
- 사장님 폰에 **Meta Business Suite 앱** 설치 → 리드 알림 켜기(설정 → 알림 → 리드). 앱에서 바로 전화 가능. 자동화 전 단계로 가장 현실적.

### 6.3 자동 전달 파이프라인 (Meta → 구글시트 → 알림톡/문자 → 사장님 카톡)

| **n8n** | Facebook Lead Ads Trigger 노드 (New lead) | 셀프호스팅 무료. **[공식 문서] 앱당 웹훅 1개만 등록 가능** → 테스트/운영 전환 시 웹훅이 덮어씌워지므로 테스트 시 운영 워크플로를 잠시 비활성화 | 무료(셀프) / 클라우드 $20~ |

**알림톡/문자 발송 [실무 통념]**
- 카카오 알림톡은 카카오 비즈니스 채널 + 비즈메시지 대행사(솔라피·NHN Cloud·카카오 공식 딜러 등) 계약 + **템플릿 사전 검수** 필요. 템플릿 예: "[○○샵] #{이름}님, 상담 신청이 접수되었습니다. 담당자가 10분 내 연락드립니다. 문의 010-xxxx". 알림톡은 정보성 메시지라 광고 표기 불필요하나, 혜택 안내를 넣으면 친구톡(광고성·수신동의 필요)으로 넘어간다.
- 문자(SMS)는 알림톡 검수 없이 즉시. 광고성 문구면 "(광고)" 표기·수신거부 번호(정보통신망법, raw 04 §6).
- n8n/Make에서 HTTP 노드로 발송 API 호출 — 개발자의 차별 상품(raw 07 §7.1).

**리드 액세스 권한 함정 [공식 기능]**: 포트폴리오 설정 → 통합 → **리드 액세스**에서 CRM/앱에 페이지별 권한을 줘야 Zapier 등이 리드를 읽는다. "연동했는데 리드가 안 옴"의 80%는 이것.

### 6.4 응대 SOP (사장님께 한 장으로)
1. 알림 오면 **5분 내 전화**, 부재 시 문자 "○○샵입니다. 방금 전화드렸어요 :)"
2. 30분·다음날·3일 후 총 3회 후속, 이후 종료
3. 리드 시트에 결과 표기: 연결/예약/노쇼/허수 — 이게 다음 달 광고 최적화 재료
4. 노쇼율 30% 넘으면 "높은 의도" 양식으로 전환·예약금 도입

## 8. 계정 정지·광고 거부 대응

### 8.1 흔한 광고 거부 사유 → 수정법 [Meta 정책 원문 + 실무]

| 거부 사유(알림 문구) | 왜 걸리나 | 고치는 법 |
|---|---|---|
| 개인 속성 | "당신 ○○하죠?" 2인칭 단정, 나이·질병·체형 언급 | 3인칭 서비스 설명으로("○○ 상담 가능") |
| 개인 건강(비포애프터·신체 이미지) | 신체 부위 클로즈업, 살 꼬집기, 기간 명시 없는 감량 결과, 18세 미만 포함 타게팅 | 전체 샷·동일 조건, 기간 표기, 18+ 타게팅 |
| 오해의 소지가 있는 주장 | "100% 효과", "1위", "무조건", 가짜 마감 | 근거·조건 표기, 표현 완화 |

| 음악/저작권 | 상업 음원, 타인 영상·이미지 | Sound Collection·라이선스 음원, 자체 촬영 |
| 텍스트 과다·저품질 | 화면 대부분이 글자, 클릭베이트 | 자막 최소화, 안전 영역 준수 |
| 제한 카테고리 | 주류·의료기기·금융·다이어트 보조제 | 카테고리별 요건(연령·인증) 확인, 의료는 심의 |

### 8.2 광고 거부 시 절차 [공식 경로]
1. 광고 관리자에서 거부된 광고 선택 → 알림의 **정책 이름** 확인 → 위 표대로 **수정 후 재게시**(대부분 재심사 통과).
2. 잘못된 판정이라고 판단되면 **비즈니스 지원 홈(business-support-home) → 해당 광고 → "검토 요청"**. 사유는 500자 이내, 정책 이름을 언급하며 왜 부합하는지 사실만.
3. 같은 광고를 **문구만 살짝 바꿔 반복 재업로드하지 않는다**(오타·기호로 필터 우회 "f.r.e.e" 류는 우회로 간주).

### 8.3 광고 계정·포트폴리오 정지(비활성화) 시 절차 [공식 경로 + 실무]
- **경로**: **비즈니스 지원 홈**(https://www.facebook.com/business-support-home — 구 "계정 품질" 페이지를 대체) → 제한된 계정 선택 → "할 수 있는 일" 섹션 → **검토 요청** → 화면 안내(신원 확인·비즈니스 인증·보안 조치) 완료 → "지원 사례"에서 상태 추적.
- **[공식·실무 확인]** 관리자만 검토 요청 가능. **180일 내** 서류 제출하지 않으면 이의신청 권리 상실. 결제 문제는 1~3일, 정책 위반은 3~10일(길면 수주). 결과: 복구 / 재이의 가능 거부 / 영구 정지.
- 준비 서류: 사업자등록증, 대표 신분증(요청 시), 광고 중인 사이트·소재 캡처, 결제 카드 명의 증빙.
- 정지 원인 비율(Leadsie 46만 계정 데이터): 정책 위반 45%, 결제 문제 34%, 계정 도용 9%, 비활성 7%. **결제 실패로 인한 정지가 1/3** — 사장님 카드 한도·만료일을 월초에 확인.

### 8.4 정지 시 절대 하지 말 것
1. **새 광고 계정·새 포트폴리오·새 페이지를 만들어 우회** — 시스템 우회로 간주되어 **연결된 모든 자산(사장님·대행사 양쪽)이 영구 정지**될 수 있다. Meta는 결제 수단·IP·기기 ID·도메인으로 연결을 잡는다.
2. **대행사 계정에서 대신 돌리기** — 1번과 같은 결과 + 대행사 다른 클라이언트까지 연좌.
3. 지인 계정·구매 계정·"에이전시 계정 렌탈" 사용(raw 04 §3).
4. 이의신청을 하루에 여러 번 반복 제출.
5. 사장님께 "곧 풀립니다" 확언. 복구 불가 사례가 실제로 많다.

### 8.5 사전 예방 체크리스트 (광고 켜기 전)
- [ ] 사장님 포트폴리오 2단계 인증 + 비즈니스 인증 완료
- [ ] 사장님 명의 카드, 사업자등록번호 입력, 카드 한도 확인
- [ ] 도메인 인증, 랜딩에 사업자 정보·개인정보처리방침
- [ ] 소재 체크: 2인칭 단정 없음 / 신체 부위 클로즈업 없음 / 기간·조건 표기 / 라이선스 음원 / 초상권 동의
- [ ] 제한 카테고리면 18+ 타게팅, 병원은 심의필
- [ ] 첫 주 예산은 일 1~2만 원으로 시작(신규 계정 급증 지출은 도용 의심 트리거) [실무 통념]

### 8.6 계약서 면책·책임 문구 (초안, 법률 자문 아님)
> 제○조(플랫폼 정책 및 계정 제재)
> ① 광고 계정·페이지·데이터 세트 등 모든 광고 자산은 "갑"(광고주) 명의의 비즈니스 포트폴리오에 귀속되며, "을"(대행사)은 파트너 권한으로만 접근한다.
> ② "을"은 Meta 광고 정책 및 관련 법령(표시광고법·의료법·정보통신망법 등)에 부합하도록 소재를 제작·검수하되, Meta의 심사·게재·제재 결정은 "을"이 통제할 수 없는 사항으로서 광고 거부·계정 제한·정지로 인한 손해에 대해 "을"은 책임을 지지 않는다. 다만 "을"의 고의·중과실로 인한 경우는 예외로 한다.
> ③ "갑"이 제공한 소재·문구·후기·인물의 권리(저작권·초상권·표시광고법상 근거)는 "갑"이 보증하며, 이로 인한 제재·분쟁은 "갑"의 책임으로 한다.
> ④ 의료광고 사전심의 등 업종별 법정 절차는 "갑"의 책임이며, "을"은 심의필 없는 소재의 집행을 거절할 수 있다.
> ⑤ 계정 제재 시 "을"은 이의신청을 대행하되, 새 계정 개설 등 정책 우회 행위는 하지 않으며 "갑"도 이를 요구하지 않는다.
> ⑥ 계약 종료 시 "갑"은 파트너 권한을 해제하고, "을"은 보유한 접근 정보를 폐기한다.

## 9. 광고비 결제·세금

### 9.1 결제 구조 정석
- **매체비는 사장님 카드로 Meta에 직접 결제**, 대행사는 **대행 수수료만** 세금계산서 발행. 매체비를 대행사가 받아 전달하는 구조를 쓰더라도 부가세 과세표준은 수수료만이지만(raw 07 §6.3), 회계·증빙이 복잡해지므로 직접 결제가 정석.
- 결제 방식: 광고 관리자 → 청구 및 결제 → 결제 설정. 신용/체크카드(자동 결제, 청구 한도 도달 시 또는 월말 결제). 선불(수동 결제)은 국내 제한적 [확인 필요].
- 지출 한도: 결제 설정에서 **계정 지출 한도**를 월 예산의 110%로 걸어두면 실수 방지.

### 9.2 사업자등록번호 입력과 부가세 [국내 세무 블로그·Meta 도움말 요지 — 세무사 확인 권장]
- Meta(Meta Platforms Ireland)는 한국에 **간이사업자등록을 한 국외사업자**로, 한국 광고주에게 현지 세율(10%)의 부가가치세를 부과한다. **[공식 요지]**
- **결제 설정 → 비즈니스 정보 → 사업자등록번호(VAT/세금 ID) 입력**하면 사업자(B2B)로 간주되어 **VAT 10%가 부과되지 않는다.** 미입력 시 광고비의 10%가 추가 청구된다. [실무 다수 소스 일치]
- **세금계산서는 발급되지 않는다**(국외사업자). 따라서 **매입세액공제 대상이 아니다.** 비용 처리는 Meta 영수증(청구 및 결제 → 거래 내역 → 영수증 다운로드/인쇄) + 카드 전표 + 계약서·집행 캡처로 한다. [실무 다수 소스 일치]
- **대리납부 이슈**: 부가가치세법 제52조상 국외사업자로부터 용역을 공급받는 자가 **과세사업에 사용하지 않는 경우(면세사업자·비사업자 등)**는 부가세를 대리납부해야 한다. 일반과세자가 과세사업(음식점·뷰티·학원 등 대부분)의 광고비로 쓰는 경우는 대리납부 의무가 없다는 것이 통설이나, **면세사업자(병·의원 상당수, 학원 중 일부)**는 대리납부 대상이 될 수 있다 → **병원·학원 클라이언트는 담당 세무사에게 "해외 광고 플랫폼 이용료 대리납부 여부"를 반드시 확인**시킨다. [세무 블로그 요지, 확인 필요]
- 대행사 자신: 광고대행업은 일반과세자 등록. 대행 수수료 세금계산서 발행. 툴 구독(Zapier·Stape 등) 해외 결제는 인보이스 보관, 같은 대리납부 검토.

### 9.3 사장님께 설명하는 문장
> "광고비는 사장님 카드에서 메타(아일랜드 법인)로 바로 빠져나갑니다. 결제 설정에 사업자번호를 넣어두면 부가세 10%가 안 붙어요. 대신 해외 회사라 세금계산서는 안 나오니, 메타 영수증을 매달 다운로드해서 세무사님께 드리면 됩니다. 저희 대행료는 별도로 세금계산서 발행해 드립니다."

### 9.4 월말 정산 루틴
1. 광고 관리자 → 청구 및 결제 → 거래 내역 → 해당 월 **영수증 PDF 일괄 다운로드** → 사장님 카톡/메일
2. 집행 캡처(캠페인 지출 화면) 1장 첨부 — 증빙 3종(계약서·영수증·집행 캡처, raw 07 §6.3)
3. 대행 수수료 세금계산서 발행(홈택스) — 매체비 %제면 영수증 합계 기준
4. 카드 한도·만료 확인(결제 실패 = 정지 사유 1/3)
